# 故障与对账记录模板

事件id/日期/负责人/状态：待填。状态：未发生或未调查。

## 事实和影响

受影响订单/实际seller/模式/资金原号/资源代次/客户端版本，首末观察时间、真实金额与数量、不可确定部分。内容/PII仅受控引用，不贴到公开事故报告。

## 控制和查核

停新资金/新单或隔离资源的实际动作；按原号查询的渠道事实；当前job/token/lock_generation与真实进程停止/清理；备份恢复后事件/删除标记；双人核对差额、冲正事件与责任。

## 修复与恢复条件

根因证据、修复commit/回归、何人批准恢复、用户权益/退款处理、剩余未知和下次核查。UNKNOWN不能直接改成功/失败，禁止删除历史账或通过换请求号掩盖重复副作用。
