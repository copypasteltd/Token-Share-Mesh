# 发布回滚记录模板

版本/commit/制品hash/签名/SBOM、环境/责任人/时间：待填。状态：未发布。

## 发布计划

适用seller/device/SKU/mode/privacy/region和证据版本；原生构建矩阵；备份与迁移；先停新单/排空；在途合同/本地密钥/资源代次兼容；配置/秘密来源；逐级放量和停止阈值。

## 执行与回滚

实际步骤/时间/结果/审阅人，探测与真实履约证据，失败回滚的制品和数据兼容。资金/租约/删除标记不可因恢复重放；不把镜像回滚当合法账务冲正。

## 交接

观测窗口、告警负责人、留存/清理、未完成事项、最终决定及证据引用。没有执行则保留未发布。
