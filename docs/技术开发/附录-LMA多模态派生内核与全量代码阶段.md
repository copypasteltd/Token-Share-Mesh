## LM-007—014：实际内核接入

上游当前实际注册18个扩展原生模块及文本运行时。相关图像/视频路线包括`sd_cpp`、`wan_sd_cpp`、`mnn_diffusion`和`ltx098_native`。有代码、已下载、能通过本项目合同准入、能在指定手机运行、可以挂牌是不同状态。

| 编号 | 生产代码 | 行为 |
|---|---|---|
| LM-007 | `MeshLmaDescriptors` | 从实际安装包、engine-builds、模型/配方/组件和真实本地文件生成描述；核对二进制摘要，保持`market_qualified=false`，不把目录登记当能力合格。 |
| LM-008 | `MeshLease` | 验证既有P11 Ed25519租约编码、独立issuer pin、本机批准、原卖家/订单/设备/物理资源及双围栏；Android媒体清单另用明确的M1版本。 |
| LM-009 | `MeshMediaRequests` | 将OpenAI图像/视频控制值转换成安装的LMA配方；精确模型别名、参数、尺寸、帧数和时长，拒绝静默参数夹取、切后端、未知字段与未批准适配器。 |
| LM-010 | `MeshMediaAssets` | 只接收原签名清单中的素材ID/角色/字节/摘要，通过有界流写入本任务私有工作区，实际检查媒体；不接受任意路径、URL或普通LMA历史素材ID。 |
| LM-011 | `MeshMediaRunner` | 直接调用`LocalEngines.require`、`LocalEngine.Context`和真实`ExecutionGate`；先取得唯一槽、停驻原文本模型，再调用同一手机的实际原生生成与编码。 |
| LM-012 | `MeshJournal` | Keystore加密的元数据日记先持久化原owner和最高代次，再执行；重复租约只恢复原记录，不再次提交；重启存在原owner则隔离。 |
| LM-013 | `MeshSharePolicy` | 用户明确开启，执行中复核充电/Wi-Fi/电量/屏幕/温控/内存与磁盘；模型峰值预算在准入时核对，运行时不重复扣除已加载模型的全部预算。 |
| LM-014 | `MeshResultCipher` | 验证真实PNG/MP4后，用64KiB缓冲逐块AES-GCM写出密文；每块绑定原租约/attempt/物理代次/token/清单/序号/长度/末块标记；不把完整视频转为内存Base64。 |

源码均位于[Android适配层](../../dev/src/client/android/overlay/app/src/main/java/com/lma/app/)。CPU与Vulkan无静默互换；模型不因远端任务自动下载、安装、修改默认参数或新增用户节点。音频/3D等上游源码一并固定，完整平台接线仍属于原DEV-41—44范围。

## LM-015—021：协议与清单

| 编号 | 固定规则 |
|---|---|
| LM-015 | 外部请求沿OpenAI/Anthropic既有分工。图像生成、图像编辑、视频使用OpenAI入口及明示扩展；不编造Anthropic生图/视频兼容接口。内部LMA Context不是对外协议。 |
| LM-016 | M1清单通过既有租约`execution_manifest_hash`绑定原始UTF-8清单字节。它与原Go文本清单的结构化摘要是不同的明确profile，不混用校验算法。 |
| LM-017 | M1包含原job/attempt/order/route/seller/device/resource/capability、资源代次/token、合同/内核/模型/配方/二进制摘要、操作/后端/别名、尺寸/帧/时长上限、原输入与硬截止。 |
| LM-018 | `request_payload_sha256`只用于当前PLAINTEXT/STANDARD入口的精确正文绑定；`input_ciphertext_sha256`保留原存储密文含义。参考素材的`payload_sha256`明确指交付正文，不偷换为资产密文摘要。 |
| LM-019 | 独立本机批准来自受保护的提供方配置，不能从任务响应自动创建。提供方选择模型、后端、共享条件和合同上限；远端只在批准范围内请求。 |
| LM-020 | 请求`n`、输出帧数、参考图数量是技术参数；交易计价仍用小时或输入/输出M token，不恢复按图收费。视频长任务必须有真实签名续约，HTTP200、进度或普通Ack不延长45秒租约。 |
| LM-021 | 私有媒体素材绑定、OpenAI multipart规范化和最终异步视频状态仍需与平台数据通道完成整体接线；此适配库不单独宣称所有公开API已可用。 |
