# 用户角色、页面字段与交互规格

2026-10-30增量：页面视觉以[NB五页规范](../../dev/design/新粗野主义-v1.0/04-五页逐屏规格.md)为准；五页动作与十辅助界面见[闭环流程](../需求推进/NB-1.0/02-页面与闭环流程.md)，字段/既有INT/缺口见[契约衔接](../需求推进/NB-1.0/03-字段动作与契约缺口.md)。小程序主导航为发现/订单/共享/我的；新售小时或输入输出M token双价，具体型号与个人卖家绑定，当前/预估/最终/到账分列。此为需求，不声明UI已实现。

P11｜v3.0｜2026-10-29｜覆盖买方、卖方、原生程序、运营、客服、财务；网页和客户端界面为需求，尚无产品UI。

当前主交易入口为React/Taro支付宝小程序；Web React/Vite提供开发者/复杂任务/运营财务。页面与分端transport/付款/加密程序边界见[前端细则](../技术开发/14-前端路由状态与接口集成.md)。

## 1. 全局交互规则

账户可切买卖视角，当前角色与实际订单主体始终可见。普通页面支持360px宽屏、桌面、键盘焦点、文字状态；日期展示含时区，排序按服务端时间。CNY显示元与两位小数，底层整数分；用量/时长单位明示，预估与实际分开。

列表至少具有初次加载、空列表、过滤无结果、刷新失败保留旧数据及采样时间、分页、权限失效、网络离线七类状态。写动作防重复提交，使用幂等请求；提交中离页可再次查询，不靠禁用按钮替代后端约束。错误含安全原因、是否可重试、下一步和请求号，不泄漏正文/内部栈。

改价、停新单、强停、结束租赁、续租、退款、密钥轮换分别展示影响。付款、放钥、公开内容、托管凭据、LAN开放等需要产品内明确选择；这里的用户操作确认不是本次文档工作需要再向项目负责人索要授权。

## 2. 买方页面清单

| 页面 | 主要字段与动作 | 异常/验收重点 |
| --- | --- | --- |
| PAGE-B01 登录与账户 | 账户、角色、设备会话、协议、撤其他会话 | 过期重新认证，不丢未提交报价引用；敏感字段不进URL |
| PAGE-B02 算力市场 | 服务/模型/模式/地区/价格/时段筛选、等待、样本、卖家 | 无合格供给不可购买；旧基准显示时间；有推荐标记 |
| PAGE-B03 卖家与挂牌详情 | 真实卖家/必要公示、设备能力、许可状态、模型、基准、费用、评价/窗口 | 未验证不显示“可售”；基础加密清楚披露卖方可见 |
| PAGE-B04 规格与输入 | 批准参数、输入/输出上限、预检、预计时限、所选模式 | 加密预检在本地；未知参数/超限/任意工作流不提交 |
| PAGE-B05 合同与报价 | actual seller、listing/version、总价/预算、佣金披露、可见方、期限/退款 | 默认不勾选；过期/变版重新报价，不沿用旧确认 |
| PAGE-B06 支付与凭证 | 渠道、对应订单、授权/实付/待查、继续查询 | 页面跳转不当到账；重复点击不重扣；未知不让重买 |
| PAGE-B07 任务详情 | 支付/执行/交付/验收/退款分栏、阶段、最迟期限、取消、证据 | 慢进度不伪造百分比；加密密文到达显示待本地接受 |
| PAGE-B08 结果与本地验收 | 格式/规格、本地解密状态、接受/拒绝及原因、下载期限 | 坏包/缺终块不成功；不会把私钥上传客服 |
| PAGE-B09 租赁准备 | 环境、预算、准备检查、连接/基准、买家ready操作 | 未ready不计费；超时可理解，不能只因在线起表 |
| PAGE-B10 租赁工作区 | 会话、有效时长/预算、受控模型与参数、队列/导出、续租/结束 | 只能自己文件/会话；无shell/安装节点；到期停止 |
| PAGE-B11 API与路由 | 平台/本地Base URL、协议档、模型、seller/listing、模式、预算/次数/到期、key管理 | 密钥创建仅一次显示，撤销立即阻新请求；不默认明文或全局池 |
| PAGE-B12 账单与退款 | 成交/用量/有效租时、费率、退款/到账、导出 | 不把授权当实付；可重算且重查免费 |
| PAGE-B13 评价与售后 | 可评价订单、评分/文本、指定举证、请求、进展/申诉 | 无有效资格不能刷评；证据公开与私密提交分开 |

买方Web可管理加密订单，但数据面需连接本机/可信LAN程序。页面只显示连接状态、协议/端点指纹、安全原因码；不替本地程序持有解密钥。工具调用显示结构化建议/结果关系，不默许执行用户或卖方主机命令。

## 3. 卖方页面清单

| 页面 | 主要字段与动作 | 异常/验收重点 |
| --- | --- | --- |
| PAGE-S01 个人入驻 | 身份/设备权利、所在地、协议、渠道收款关系、材料及申诉 | 缺证显示具体项；不要求先签平台采购合同 |
| PAGE-S02 设备与配对 | 设备别名、系统/引擎、配对码/过期、撤销、身份/密钥指纹 | 不公示硬件唯一敏感标识；重配不继承旧租约 |
| PAGE-S03 安装与模型 | 安装位置、分项体积、来源/许可、进度/暂停/取消、校验 | 用户主动下载，不改全局引擎或误删自有模型 |
| PAGE-S04 能力与基准 | 实际后端、已装/已载/已测/可售、样例/失败率/版本 | CPU不冒称GPU/NPU；基准缺样本不标完成 |
| PAGE-S05 挂牌编辑 | SKU、模式/隐私、设备集合、未来价、时段/并发、接单规则、费用 | 价格单位必选，旧合同不改；不合格组合不能发布 |
| PAGE-S06 共享控制台 | 接单/排空、活动任务、资源/网络/热状态、强停 | 停新单不误停当前；强停显示后果，未知指标不编造 |
| PAGE-S07 订单履约 | seller固定、租约/attempt、进度、交付/回执、故障上报 | 只有本卖家能看/执行，旧token不补正式结果 |
| PAGE-S08 收益与结算 | 成交额、佣金/渠道费、应结/冻结/渠道状态、实际到账、对账 | 待结不叫已到账；无订单不显示保底收益 |
| PAGE-S09 评价与申诉 | 真实评价、样本、回复、处理理由、申诉/恢复 | 无付费删差评，不能泄露买方私密素材 |
| PAGE-S10 退出与设备转让 | 在途列表、停止新售、清理/撤证、尾款/争议、模型保留选项 | 未清理不再出租；转让重登记，历史收益不移归新主 |

## 4. 本机/LAN程序界面

PAGE-L01首次启动：选择买方/卖方/双角色、安装路径、单独数据目录、配对和默认loopback。PAGE-L02连接设置：本地端口、协议档、路由合同、区域、接收端指纹、预算和凭据状态；敏感值掩码，仅本人可临时查看。

PAGE-L03 LAN开放：明确监听接口、HTTPS证书/配对、允许设备/范围、撤销、流量/并发及风险可见方。LAN不默认开放0.0.0.0，无宽泛CORS；证书错/未配对拒绝。PAGE-L04加密任务：请求/流ID、加密/解密阶段、终块校验、回执/错误，默认无正文调试。

PAGE-L05密钥与更新：生成/备份指引、指纹、轮换/撤销、独立发布物校验；平台不能恢复内容钥。PAGE-L06日志与诊断：采样范围、脱敏预览、用户主动选择导出，禁止默认上传完整上游包、提示词或崩溃内存。

Android共享控制须有持续可见状态/停止入口，后台、锁屏、撤权和热压力给出具体暂停理由。个人聊天/本地API与共享任务分视图但共资源槽，退出共享不删除个人资料。

## 5. 后台与分权

| 页面 | 角色 | 允许动作与二次约束 |
| --- | --- | --- |
| PAGE-O01 准入/许可 | 运营/许可审核 | 核材料、批准/退回、有效期；不能代替渠道审批或自批自己的卖家 |
| PAGE-O02 目录/发布矩阵 | 发布负责人 | 绑定版本/证据启停单组合、回滚；无证据不能强开增强/收费 |
| PAGE-O03 调度与节点 | 运维 | 查看安全遥测、隔离、排空；无任意主机shell或内容解密 |
| PAGE-O04 市场秩序 | 运营/复核 | 评价处理、关联风险、处罚/申诉、理由审计；无造单造评 |
| PAGE-C01 售后工单 | 客服 | 查合同/时序/证据引用、请求特定授权；财务不因此获得正文 |
| PAGE-C02 明文排障授权 | 经授权客服 | 订单/目的/人员/期限限定；加密仅接买方选择性披露副本 |
| PAGE-F01 资金与对账 | 财务 | 交易/退款/佣金/卖家款差异、渠道查单、补充证据；无修改历史金额 |
| PAGE-F02 渠道结算 | 制单/复核分权 | 指定卖家/可结项、渠道前置检查、双人审批、未知查原项 |
| PAGE-A01 权限与审计 | 受控管理员 | 最小权限、会话/密钥撤销、配置审核；不能获取内容钥或绕资金门槛 |

## 6. 关键跨页状态

付款晚到且资源已释放：支付页显示“付款已查明、履约重新核验/退款”，不直接启动新任务。加密本地程序未连接：合同可查看，内容不提交，显示安装/连接指引。换卖家：新详情和报价明确展示与原单关系，旧费用不被覆盖。

结束租赁后：工作区即时撤权，账单结算与节点清理分别显示；导出只在已授权期限可领。服务端未知时：页面展示待查，不将HTTP请求超时包装成明确失败/成功。无障碍验收覆盖焦点恢复、错误关联字段、文字说明及不只靠颜色表达状态。

## 供给方内核管理交互

新增本地内核页：CLI/daemon/runtime或ComfyUI/Python/节点/媒体组件版本、当前环境摘要、模型/能力包、候选版本差异、许可/下载量/新增权限、验证结果、切换/回滚状态。提供方主动选择批准组件与共享范围；买家不获得安装权。Android二开页面复用本机状态，并持续通知共享/停止。小程序仅摘要管理，安装/维护需在本人本地授权域完成，不能凭小程序远程要求任意执行。
