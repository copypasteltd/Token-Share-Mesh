## 2. 端、模式与设备矩阵

| 轴 | 必测集合 | 说明 |
| --- | --- | --- |
| 桌面 | Win-ComfyUI、Linux-ComfyUI、Win-LM Studio、Linux-LM Studio | 原生物理机，版本分别记录 |
| 手机 | 至少两款不同系统/资源Android真机 | 真本地推理、锁屏/后台/热/切网，不用构建或模拟器替代 |
| 模式 | 明文、基础E2E、标准整卡租赁 | 每一已发布组合独立测；Android不测不存在的整卡租赁 |
| 增强 | 合格自愿卖家设备的全路径真实证明 | wrong challenge/key、过期、撤销、度量变化、明文逃逸 |
| 协议 | OpenAI Chat、Responses、Anthropic Messages | JSON/SSE/工具/错误与所售媒体子集，固定真实SDK版 |
| 网络 | loopback、主动LAN、NAT出站、断线/切网 | 鉴权/证书/撤销、背压/截断、恢复边界 |
| 资金 | 沙箱、获准正式个人卖家交易/结算 | 分环境；无实际到账不能报完整平台闭环 |

两位卖家各一台节点可以验证C2C交易和跨卖家重选，但同卖家重派必须一位卖家登记两台真实独立节点，另需另一卖家验证跨卖家新单。不得用同机两进程冒充物理故障切换或平台自营机器替用户供给。

## 3. 核心完整演练

| 场景 | 正向链路 | 负向/恢复证据 |
| --- | --- | --- |
| C2C明文 | 自愿入驻/挂牌→买方确认→真实资金→节点→平台接受→卖家净额/佣金→渠道到账 | 撤证/缺许可、无供给、支付未知、坏产物、取消竞态、重复20次回调 |
| 基础E2E | 本地程序/独立端点→加密→平台盲转→卖方内核→加密回传→本地回执 | 平台日志/对象/流无明文、错钥/串单/截断、无回执、换端重放钥 |
| 增强 | 新鲜证明→买方策略验证→保护区放钥/全路径执行 | 普通进程假冒、CPU/编码/日志逃逸、旧证明/更新/外部出口拒绝 |
| 租赁 | 预留/准备零费→双端ready→有效可用时长→结束撤权/退款→清理再租 | 9分10秒算例、检测尾段不收、断线/到期重启、未清理禁复用 |
| 统一API | 固定SDK/档位→JSON/SSE/工具→真实后端→标准回包 | 同步202混用、丢字段、假usage、SDK无稳定键、模型别名换卖家 |
| Android | 主动共享→资源条件→真机本地任务→账/停止 | 热/低电/切网/后台杀、个人任务抢槽、权限撤销、清数据重配 |
| 资金售后 | 唯一账→退款/部分退→重算佣金→结算与申诉 | unknown重复出款、收款归属不符、已到账退款、无渠道禁售 |

参赛包包括作品说明、定位/架构、已发布组合、公开访问与试用说明、真实支付/交付/个人卖家结算脱敏证据、演示视频/脚本、合法样例、用户反馈和公开互动。主办方报名/接入账户一致性及有效交易口径须核；本地订单表不能自动认定赛事有效用户。

10分钟路演可按问题/用户1分、C2C卖家挂牌1分、买方发现/支付/交付3分、加密与标准API2分、真实数据/成本1分、风险/边界/计划2分安排；只是项目演示建议。决赛评分以官方新规为准，不沿用初赛权重冒称最终算法。
