# 商业模型、运营实验与风险登记

P11｜v3.0｜2026-10-29｜C2C市场经营设计。金额/转化/规模均为H假设，没有访谈、真实交易或财务验证。

## 1. 双边价值和验证对象

买方价值假设是更易取得适配场景的计算结果/应用时段、标准API接入和可选择的隐私边界；卖方价值假设是无需自搭公网服务/找客/收款即可变现闲置窗口。平台应证明匹配与交易便利的价值，不能只做供给数量展示。

桌面GPU、手机文本、授权上游、增强隐私为四种不同经济单元，价格/稳定性/客户群分别验证。Android计算价值可能被现成廉价API和热/后台成本压缩；增强硬件稀缺且成本高；生视频等待和售后比图像更重，不能共用同一乐观毛利率。

## 2. 单位经济与敏感性

`净成交额=已合格且最终收取GMV-退款`；`平台收入=已实现明确佣金+服务费`；`贡献=收入-平台承担渠道费-中转/存储/验证/连接成本-实际损失-变量支持/获客成本`。卖家回报另外扣自己电费/损耗/网络/税费/机会成本，不能把平台给出的应结额直接称净利润。

纯假设按3元/有效GPU小时成交，平台变量成本0.27元/小时：10%抽佣收入0.30贡献0.03，15%收入0.45贡献0.18，20%收入0.60贡献0.33；卖家应结分别2.70/2.55/2.40元，未扣自身成本。此表不是价格/费率建议或预测，尤其未含v3.0新增加密/LAN/手机实测成本。

若假设月固定成本3万元、15%佣金及上述贡献，需要约166,667有效GPU小时覆盖；若每台每月720小时且30%售出，即约772台等效设备。只是算式敏感性，不能当启动规模或供需预测。费用取整和1分钱小单可能使佣金为0，需透明订单设计与渠道支持，不能造钱包/隐藏最低费。

## 3. 经营指标口径

| 指标 | 分母/口径 | 防误读 |
| --- | --- | --- |
| 有效供给 | 自愿已核验且对应时段/能力可售的seller/device | 注册/下载/在线数不等于产能 |
| 可售/售出率 | 同口径可确认可售时长与实际合格成交 | 不把故障/租赁占用算未售库存或重复供给 |
| 匹配转化 | 有明确需求的搜索→可接受报价→确认→有效成交 | 无供给/拒绝/超时计入，不剔困难请求美化 |
| 履约率 | 全部受理任务/会话，各模式分别 | 加密未验收非成功，租赁零产物非失败 |
| 实付买方/复购 | 独立有效付费、去除测试/关联套利；窗口明示 | 不以GMV/注册数/参赛自己付款替代 |
| 卖家净回报/留存 | 实际到账、资源成本/机会成本、继续开放 | 待结不当到账，短期补贴不当持续回报 |
| 平台贡献 | 实现佣金与实际变量成本 | GMV不全算收入，补贴/赔付单列 |
| 信任/质量 | 退款、争议、申诉改判、清理/隐私事故 | 无投诉不等于安全，证据范围需可说明 |

## 4. 实验计划

先访谈真实目标买方的任务类型、现有替代、等待/隐私和愿付价；卖方记录可开放窗口、电价/功耗、设备损耗认知和自用冲突。访谈/意愿不是成交证据。邀请试点可限人数，但供给仍是个人自愿挂牌，不由平台自有卡伪装。

首轮只用已证明的一个配方/路径收集完整搜索→收款→交付→个人结算→反馈；扩展到手机/增强/视频时另设假设与证据。样本不足只报观察，禁止无统计依据的获客/获奖/收益概率。所有公开案例需独立授权，私人订单不自动进入图库或训练。

## 5. 风险登记

| RISK | 触发/风险 | 处置与退出证据 | 责任角色 |
| --- | --- | --- | --- |
| R01 供需不成立 | 挂牌多但无复购/费后回报低 | 明确场景、真实小样本闭环、双方回访及贡献，达不到停止扩量 | 产品/运营 |
| R02 个人资金资格 | 仅平台商户收款、不能识别卖家结算 | E证据确认服务类别/个人seller/退款佣金结算，否则禁收费 | 财务/合规 |
| R03 订阅转供权 | key可用但下游用途无许可 | 逐主体/套餐/地区书面或正式许可，默认关闭 | 许可审核 |
| R04 引擎/模型许可 | 本地免费/代码MIT被误当服务许可 | 软件/依赖/权重/输出及分发分别审批 | 法务/工程 |
| R05 平台改成B2C | 默认买断、保底或账号池售卖 | 检查seller合同/定价/GMV及路由，回归C2C不变量 | 产品/财务 |
| R06 设备离线/异构 | 自用/掉电/慢节点 | 真基准/准入/有限同卖家重派、原单失败与责任 | 调度/客户端 |
| R07 锁/清理失败 | 多引擎超卖、未停任务就再租 | 统一锁、fencing、清理确认/隔离与故障演练 | 调度/安全 |
| R08 伪加密 | 平台解密/明文日志/媒体链接 | 双端数据流和对象/遥测泄漏测试，禁售受影响组合 | 安全/网关 |
| R09 主动换钥/更新 | 恶意目录/发布物 | 独立端点确认、发布校验/可信更新，变化停放钥 | 安全/客户端 |
| R10 假增强 | 普通CPU/LAN内核先解密 | 全路径真实证明/公钥绑定，无证据不贴增强标签 | 安全/硬件 |
| R11 加密拒收 | 内容已解密无回执 | 事前限额/责任、反滥用、可选择举证，不能自动成功扣 | 风控/产品 |
| R12 协议丢语义 | 工具/思考/usage被丢或伪造 | 档位/版本/拒绝表，SDK回归，不能宣传全兼容 | 网关/测试 |
| R13 SDK重试双单 | 无稳定键/执行未知又购买 | 幂等scope/配置重试边界、查原单、不按正文盲去重 | 后端/SDK |
| R14 伪用量/超预算 | 自报tokens或长流失控 | 可信usage、上下文/输出/费用上限，未知不估算扣 | 计量/风控 |
| R15 Android不稳定 | 热/后台杀/拔电/切网 | 真机门槛、轻量内核、可见停止，不承诺常驻收益 | Android工程 |
| R16 内容/数据义务 | 公开生成服务/隐私/跨域角色不清 | 核实际主体/地区/用途，端点政策/标识和数据合同 | 合规/隐私 |
| R17 LAN开放代理 | 匿名监听/SSRF/网页越权 | 主动HTTPS配对、Origin/Host/目标白名单、撤证测试 | 安全/客户端 |
| R18 资金未知/双出款 | 查询超时、重复批次 | 原交易/批次去重、双人复核、每日对账，未知不重发 | 财务/后端 |
| R19 补贴刷单/假评价 | 关联买卖、虚构数据 | 有资格评价/申诉、反关联审查、排除无效收入/指标 | 风控/运营 |
| R20 运维/依赖事故 | 版本漂移、备份复活内容 | 锁定依赖、签名/排空/回滚、恢复对账与删除标记 | 运维/工程 |
| R21 小额经济不成立 | 佣金被取整/通道费带宽吃掉 | 真成本测算、透明同卖家订单设计，停止亏损扩量 | 财务/产品 |
| R22 赛事口径误认 | 模拟支付/平台GMV当官方有效用户 | 官方账户/接入/有效交易核验，不造量/自买自卖 | 项目负责人 |

## 6. 内容、平台与法律适用

交易平台的身份核验、规则、信息/评价和必要处置义务按实际活动核定，C2C不概括免责；参考[电子商务法](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_d337c3291e8b40459ca03dea54395856.html)。数据角色、授权/告知、敏感数据及跨域传输需按真实合同/地区分析，不能把加密元数据当无个人信息。[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。

向境内公众提供生成服务时需核[生成式AI暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)等适用义务，不能自动从内部研发例外推到公开平台；必要的内容/标识处理在相应明文管线或被批准端点落实。[生成内容标识官方说明](https://www.cac.gov.cn/2025-03/14/c_1743654685896173.htm)已说明显式/隐式及相应交付场景。无法同时满足隐私合同和必要处理的SKU不开放该模式。

## 7. 停止扩量条件

无合格资金或许可、持续亏损但无可验证改善、卖方/买方不愿持续、严重隐私/越权/清理/计费缺陷均先停受影响新售。保留已付单查询/退款/申诉和合法尾款处理，不能用继续卖单覆盖历史亏空或以关站免除责任。

## 内核路线的经营约束

Windows LLM确定CLI体系封装，但CLI MIT不能证明llmster/runtime的C2C收费和再分发许可；优先设计官方获取/导入，许可缺失仍不售。ComfyUI扩大音频/3D不代表默认增加销量或收益，新增节点代码/依赖、权重/声音及3D资产的使用/输出许可分别核验。内核维护期不向买家计为可用租时，不承诺所有更新均可无损回滚。
