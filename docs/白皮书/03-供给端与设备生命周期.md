# 供给端、设备及引擎生命周期

P11｜v3.0｜2026-10-29｜关联F03—F06、F11—F13、F22、F41、F57—F68、F73/F80。全部采用原生物理机/Android真机，当前无设备通过证据。

低开销完整方案（最新用户确认）：用户允许新增隐私档可嵌入LLM内核，LM Studio继续保留兼容。采用llama.cpp C API原生worker、ComfyUI私有管道入口、LMA内部JNI；买卖端加密/平台盲转，任务数据加密而模型保留原生加载，不使用VM/RAM盘/常驻第二份模型。输入准备和密文交付不额外占GPU锁，控制与大数据通道分离。内存/性能为待实测验收预算，完整链路、二进制协议、媒体、恢复及PE-01—PE-08见[完整实施方案](../技术开发/附录-低开销隐私执行完整方案.md)。当前尚未实现或通过设备/密码/性能验证。

本地隐私目标修订（2026-10-29）：提供方管理权/资源透明与买家正文隔离同时成立。首期采用原生低权限执行、密文工作区、封闭内容接口的设计，按具体引擎版本验证；LM Studio诊断/裸HTTP与ComfyUI原生历史/输出须单独封闭。详见[本地防护规范](../技术开发/附录-本地内容隐私防护与分级验收.md)，尚未实施。

## 1. 支持矩阵与适配器

| 组合 | 能力目标 | 单独核验 |
| --- | --- | --- |
| Windows＋GPU＋ComfyUI | 批准图像/视频/音频/3D能力包，受控租赁 | 驱动/依赖/显存、固定图、编码、路径与取消 |
| Linux＋GPU＋ComfyUI | 同上，原生无GUI服务，四类媒体分别验证 | 发行版/架构/权限、信号/重启、真实物理GPU |
| Windows＋GPU＋LM Studio | lms CLI＋llmster＋可替换runtime，本地文本/流式 | 引擎服务许可、API/认证、模型/量化/实际offload |
| Linux＋GPU＋LM Studio | 同CLI封装合同，独立核原生运行时及许可 | 原生进程/服务、版本/后端与许可不能套桌面结论 |
| Android基于LMA二开 | 本机轻量推理、明文/基础加密 | ARM/系统/运行时、真机模型、资源/后台与轻量网关 |
| 获准上游Relay | 许可范围内调用 | 卖家/套餐/地区/下游授权、窗口/usage、上游可见方 |

适配器统一describe/probe/prepare/execute/progress/cancel/collect/cleanup/health语义；这些是本平台内部合同，不是引擎保证自带的接口。保存真实request/prompt/job ID、当前attempt/token与资源锁，避免超时后盲重跑。

## 2. 安装、配对与状态

用户先查看组件/模型体积、许可、目录和网络成本，再选择下载。Windows便携/安装形态、Linux CLI/服务、Android App均不得静默改全局包、开机自启或接管无关引擎。Linux不得用WSL代验，Android不得用模拟器代验；开发产物全部在本项目runtime。

设备状态：UNPAIRED→PAIRED→PROBING→NEEDS_COMPONENTS/BENCHMARKING→QUALIFIED→ONLINE；可进入DRAINING/OFFLINE/CLEANING/QUARANTINED/REVOKED/RETIRED。资格按能力而非整台设备一次全开。安装、已加载、已测试、已许可、资金准入和当前可售是不同字段。

一次性配对码有短期限/尝试上限，绑定已认证账户并生成独立设备身份。撤证先关新单和在途权限，旧凭据不可恢复；重新安装/转让产生新身份，历史收益保留账户归属。硬件型号/指纹用于诊断，不能作为认证秘密。

## 3. 能力登记与基准

登记OS/架构、GPU/驱动/后端、内存/显存/磁盘、运行时/模型/tokenizer/模板/量化哈希、工作流/编码器、支持协议、资源/隐私模式、地区/数据处理方和许可证据。实际GPU offload要通过运行证据；回退CPU须重新标能力/时延，不延用GPU报价承诺。

图像每工作流至少三个固定授权输入，暖机/多次重复，正式发布初拟30次；分别记录冷启动、排队、计算、编码、上传、验收、峰值资源和失败。文本记录输入/输出长度、首token、持续吞吐、总时限、取消后计算停止与并发行为。手机测试短任务和持续负载、充电/热状态、屏幕/后台与网络切换。

只有满足SKU规格、许可和可重复成功条件才进入可售矩阵，不能仅凭型号推导速度。模型/驱动/内核更新、热限制显著变化或失效证据触发重测；普通周期抽检频率为待实测配置，失败先降可售状态，不篡改历史基准。

## 4. 资源与本地安全

一个gpu_resource_id由统一门闩管理ComfyUI、LM Studio、明文、加密、租赁及准备/清理；不能每个引擎自认有一张卡。桌面初期只接明确选定的一张卡/一槽，多GPU/并发要独立证据。整卡租赁前确认自用/显示等占用可控，不能保留半张卡又卖整卡独占。

任务目录按租户/attempt或会话隔离，模型只读，输出只从本次白名单收集。防绝对路径、..、链接/重解析点越界、压缩炸弹和任意URL抓取；外部进程用参数数组，不拼买方shell。引擎只听loopback专用端口且鉴权，不开放原生ComfyUI全WebUI或公网端口。

普通进程权限控制只能约束平台软件，不能阻止恶意主机管理员。买卖双方需知道此边界；增强档另有保护区证明。混入无关引擎任务时先隔离，不能盲interrupt影响所有者私人工作。

## 5. ComfyUI与LM Studio

ComfyUI锁定Python、引擎、节点、模型/字体许可、固定图与参数schema。提交/prompt保存prompt_id，/ws只作进度，/history恢复真实任务；/interrupt需当前prompt归属确认，/free仅在无活动占用时运行。不能接买方任意JSON图、pip安装或未知反序列化模型。[官方接口](https://docs.comfy.org/development/comfyui-server/comms_routes)。

Windows LM Studio主路线为lms管理llmster及推理runtime的可替换封装，三层版本/归属和配置域分别核验；已有桌面实例仅本人明确选择的兼容路径。不读个人聊天。模型列表可能含未加载模型，就绪需加载/身份/资源/样例均满足；冷启动计入合同期限。断HTTP不必然停止推理，cancel需后端停止/状态查询证据。API相似不能推导Responses、工具、视觉、结构化输出全部存在。

桌面条款、headless发行物和模型许可分开核验。已有资料提示LM Studio桌面对外收费服务需额外核许可，llmster具体条款仍待确认；不能因为本地API可用就默认C2C可售。[官方条款](https://lmstudio.ai/app-terms)、[既有核查](../资料/LMA与LMStudio接入核查-2026-10-29.md)。

## 6. Android与LMA

LMA确定为锁定源码二开基座，在本项目维护派生工程，不假定上游已具备平台协议、GPU/NPU、生图视频、稳定后台或真机商业验收。手机必须在本机执行，不把请求转PC/云后声称手机供给；网关可经LAN部署，但推理位置和可见方须真实披露。

用户主动共享、可见通知与立即停止入口；默认充电、非计费Wi-Fi、用户开放时段。电量/热/内存/存储/网络条件不足则暂停新单并按策略处置在途，未知传感器显示不可用。系统/厂商杀进程、Doze、锁屏、来电、撤权、切网、拔电均需真机故障测试，不root、不承诺无限保活。

个人聊天、个人API、多模态与共享订单共用本地执行门闩。清数据/卸载撤旧凭据，重新配对，个人模型是否保留由用户决定。轻量协议/加解密内核不能要求完整中心数据库栈；依赖语言/体积/生命周期在实施时冻结。[Android官方限制](https://developer.android.com/develop/background-work/services/fgs/timeout)需按实际前台服务类型解释，不把某类型6小时时限套所有类型。

## 7. 更新、恢复和退出

升级包带签名/哈希、依赖/许可、变更、适用系统和回滚版本；先停新单/排空再升级。存在紧急撤销时按在途合同失败处置；环境/密钥变化重新登记/证明，不静默换模型完成旧单。

崩溃恢复先读本地持久状态和后端ID，向平台核当前token；未知执行只查原任务，不再POST第二次。离线不延长租约或售出新容量。清理成功才解除锁，失败进入隔离；节点成功交付/会话结束1小时内清理、失败终态/离线重连24小时内补清为初拟上限，恶意所有者可能留副本的边界不得隐藏。

卸载提供保留个人模型与删除本平台目录选项，避免误删用户已有引擎。尾款、历史交易和申诉不随设备文件删除消失。安装/更新/恢复/退出文档、SBOM与真实组合报告都是发布物。

## 8. 内核替换与有限节点目录

提供方客户端与内核解耦，Windows LLM基于LM Studio CLI体系、媒体基于完整ComfyUI，Android基于LMA源码二开。ComfyUI节点必须平台批准精确修订/代码及依赖闭包，提供方选择安装，买家只给有界参数。启用目录在导入前核验；Manager目录可发现不表示可安装，venv不是恶意代码沙箱。

环境受签payload的原始字节摘要kernel_environment_digest进入能力、报价/合同允许环境集合、执行清单/租赁grant、适配器命令及任务账。报价后环境变更需重确认；已售原环境履约，不可热换内核。替换先暂存校验、停新单/排空、维护门闩、实际停止/清理、测试及资格更新；失败只回滚仍获准环境，最高围栏/身份/账证不回滚。Android可执行内核随受签APK替换，模型独立选择下载，不热加载任意下载代码。

提供方看见版本/节点/模型、更新差异/权限、活动任务与收益并可停止。详规及字段见[内核规范](../技术开发/附录-供给端内核封装与替换规范.md)，均未实现/未实机验证。
