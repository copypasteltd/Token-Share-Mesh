# 供应者客户端与 ComfyUI 封装专项规格

P11｜v3.0｜2026-10-29｜保留原生ComfyUI封装细节，扩展多端/多引擎和三模式职责。Windows/Linux双引擎及Android详见[多端矩阵](供给端/00-供给端能力矩阵.md)。当前未实施，无Docker/WSL/虚拟机/Android模拟器调度。

低开销完整方案（最新用户确认）：用户允许新增隐私档可嵌入LLM内核，LM Studio继续保留兼容。采用llama.cpp C API原生worker、ComfyUI私有管道入口、LMA内部JNI；买卖端加密/平台盲转，任务数据加密而模型保留原生加载，不使用VM/RAM盘/常驻第二份模型。输入准备和密文交付不额外占GPU锁，控制与大数据通道分离。内存/性能为待实测验收预算，完整链路、二进制协议、媒体、恢复及PE-01—PE-08见[完整实施方案](技术开发/附录-低开销隐私执行完整方案.md)。当前尚未实现或通过设备/密码/性能验证。

本地隐私目标修订（2026-10-29）：提供方UI只见组件/模型/节点、资源、任务阶段及收益，并保留停止权；正文进入独立低权限执行服务，任务文件加密，不从普通日志/预览/原生历史或文件接口读取。ComfyUI需源码内路由鉴权、受保护本地链路及首次写盘前加密；LM Studio必须单独验证lms日志通道及本机HTTP最后一跳，未封闭不得宣称已防日志/抓包。当前以提高日常访问成本为目标；策略与隐私补丁按环境摘要重新核验，见[细则](技术开发/附录-本地内容隐私防护与分级验收.md)。未运行实机。

本轮修订：小程序React＋Taro优先，独立Web React＋Vite；部署/HTTPS/运维与可观测性延后。以[当前范围](技术开发/附录-本轮范围与端侧选型修订.md)、[协议转发](技术开发/07-统一协议网关与Sub2API改造.md)和[赛事收单](技术开发/13-支付退款账务与渠道结算.md)覆盖相冲突段落；原F/T编号保留，不代表全部在本轮实施或已通过。

完整深化与实施细则见[白皮书阅读导航](白皮书/00-阅读导航与需求基线.md)和[80项逐项实施规格](白皮书/15-需求逐项实施规格.md)。本文件保留快捷需求入口；v3.0新增详规、契约和追踪，不代表软件已实现。

当前供给内核路线：Windows/Linux隐私LLM以llama.cpp原生worker封装，LM Studio的lms CLI＋llmster＋runtime保留兼容；图像/视频/音频/3D以完整ComfyUI原生内核及有限节点白名单封装；Android基于LMA源码二开。Linux原生双引擎保留。详见[内核封装与替换规范](技术开发/附录-供给端内核封装与替换规范.md)，当前均设计待实现，第三方许可/实机证据未取得。

## 产品形态与安装体验

Windows提供原生界面/Runner，Linux支持无GUI的CLI/服务，Android为原生App/服务加本地引擎。Windows LLM以lms CLI管理llmster及可替换推理runtime；ComfyUI封装独立Python/依赖/节点/媒体工具的完整可替换原生环境。Android基于LMA源码二开，不接管个人会话/引擎。自启默认关闭，不默认全天共享，不改全局包或要求公网映射，UI技术另冻结。

供给均为自愿挂牌的用户闲置设备；平台不自营或采购，卖家自主定价/时段并接受[C2C规则](交易/C2C交易与市场规则.md)。首次向导依次展示：个人卖家/平台协议与买卖合同边界、费用及隐私 → 设备兼容性检查 → 安装位置/磁盘预算 → 组件、模型来源与许可 → 下载校验 → 配对 → 基准测试 → 共享时段/资源限制、挂牌价/佣金/接单策略 → 明确预计费后收益及强停后果 → 自愿开始接受任务。下载前显示分项体积与可用空间，失败可断点重试/取消，取消不把半下载模型标为可用。

客户端首页显示设备身份、已批准能力、网络/引擎/模型状态、接单开关、排空和强制终止、当前任务阶段、显存/磁盘、挂牌/改未来价格/下架、成交额/佣金/渠道费/应结净额/到账状态、评价回复/申诉及日志导出。日志导出默认脱敏，用户主动选择文件；不自动上传完整硬盘诊断。

## 加解密程序与内置转发内核

客户端增加卖方执行网关；收到密文时先核合同/端点/租约再本地解密，交内置Sub2API类转发内核/适配器执行，返回JSON/SSE/媒体前加密。标准请求可来自买方本机或可信LAN加密程序，平台仅盲转。ComfyUI原生接口只在适配器内，外部统一OpenAI/Anthropic入口；配置、取消、计量不绕资源锁。

买卖角色可共用安装包但凭据/端口/数据分开。默认loopback鉴权，LAN需主动配对、HTTPS和访问限制；网关主机的内容可见方须披露。桌面内核优先原生模块/受限子进程，手机采用轻量实现，不要求完整中心栈。普通网关进程解密只满足基础档；增强档必须保护内核与完整执行路径。见[完整协议](协议/统一API与本地加密网关需求.md)。

## 运行布局和进程

开发测试的全部业务文件位于 `E:\dev\sandbox\支付宝黑客松\算力共享平台\runtime`。未来供给者自己的安装目录由其选择，以下为产品布局示意：

```text
supplier-client/
  client/                 桌面壳、设备控制与签名校验
  kernels/<kind>/<digest>/ 不可变内核环境、CLI/daemon/runtime或ComfyUI/Python/依赖
  kernel-registry/        已校环境清单、active引用、节点白名单与同意记录
  models/<sha256>/        经许可模型，内容寻址
  dev/workflows/<version>/    审核工作流和参数 schema
  tasks/<attempt_id>/     本次输入、输出、运行状态
  state/                  本地幂等账、配对、租约映射
  logs/                   脱敏滚动日志
  licenses/               依赖许可、对应源码/获取指引
  updates/                校验后的待应用版本
```

每次 attempt 有独立目录；拒绝绝对路径、`..`、NTFS 重解析点/符号链接越界及未经允许的扩展名。模型目录只读使用，输入写任务目录，输出只能从当前任务白名单清单上传。调用外部进程使用参数数组，不拼接用户 shell 文本。

监督进程/移动服务负责身份/心跳/资源/更新，适配器负责引擎；持久化attempt/session/token、后端ID和对应完整性证据。各OS用适用受保护存储；加密平台侧不存明文哈希/内容钥。系统凭据保护不让所有者看不到推理明文，增强档另需完整保护路径。

## 兼容性与资源控制

支持目标为Windows/Linux＋GPU双引擎及Android，只将实测OS/架构/驱动/后端/模型组合标可售，最低资源由基准决定。桌面多GPU初期只接明确指定的一张；同GPU两引擎/三模式共一个活动槽。手机实际CPU/GPU等后端独立探测，不假定桌面CUDA或NPU，不做跨节点训练。

准入前检查磁盘/内存/驱动/显存、模型完整性和网络。显存不足、用户保留量不足、磁盘低水位、过期工作流、热状态异常等暂停新租约；运行中使用资源超限先按策略中止并报告。功率/温度可用性因设备和 API 而异，读不到就显示“不可用”，不伪造安全读数或私自调整超频/电源配置。

基准集至少每工作流 3 个固定输入，含暖机和多次重复，记录加载/计算/上传耗时、峰值显存、产物规格和失败原因；正式发布另跑 PRD 中 30 次样本。节点上报和平台抽检一起决定可售能力，不信任单一 GPU 型号字符串。供给者可填写本地电价，以可测功率/运行时长或明确标注的假设估算电费；成本估算、成交额、平台扣费、卖家应结款和到账分别展示，不把“收入减估算电费”称作包含设备折旧、网络和税费的净利润。

## 工作流包合同

一个工作流包至少包含：workflow_id/version、引擎 commit/version、模型名称/哈希/许可、节点与依赖版本、参数 JSON Schema、输入映射、固定图节点、输出节点清单、资源上限、默认超时、验收规格及包签名。客户端只接受由平台批准密钥签名且未撤销的版本。

买家可改的参数逐项列白名单，例如提示词长度、seed、允许分辨率；参数映射到固定图的指定字段，不能增加节点、修改 class_type、指定本地路径、添加下载 URL 或运行命令。随机种子用于可追溯，不承诺不同 GPU/库版本逐像素一致。

模型/第三方节点与 ComfyUI 分别审核。优先避免需执行不可信反序列化的未知模型文件；即使有哈希，也须检查来源和加载方式。依赖下载仅允许固定清单、固定版本和校验值，不给买家任意 pip 安装能力。

## ComfyUI 本地适配

依据 [ComfyUI 自托管官方接口](https://docs.comfy.org/development/comfyui-server/comms_routes)，本地适配按锁定版本验证以下行为，不使用 Comfy Cloud 接口冒充本地接口。

| 动作 | 本地接口 | 平台如何使用 |
| --- | --- | --- |
| 能力检查 | GET /system_stats、GET /object_info | 配合文件哈希与样例测试，不仅凭接口在线即认为可售 |
| 提交固定工作流 | POST /prompt | 保存返回 prompt_id；返回校验错误不算开始成功 |
| 进度 | /ws | 只用于进度与诊断；重连后按记录恢复 |
| 完成确认 | GET /history/{prompt_id} | 检查具体任务输出，之后平台还需独立验收 |
| 队列与中止 | /queue、POST /interrupt | 只操作专用引擎内确认属于当前租约的任务 |
| 资源释放 | POST /free | 无活动任务且兼容当前版本时释放模型，不能误杀用户其他引擎 |

隐私原生LLM/Comfy入口走受控管道且不开正文TCP端口，LMA走内部JNI；其他已披露兼容分支仅专用loopback，不开放公网或给买家完整本地Web UI。loopback不防同机管理员，明文/加密基础档仍信任供给者；增强档须独立验证，不能沿用普通进程假冒保护。

特别是 `/interrupt` 中止的是该引擎当前执行项，不能只拿平台 job_id 就调用。客户端先验证引擎归属和当前 prompt_id；如果引擎混入外部任务，不盲目中断，隔离该设备并上报。首版使用专用引擎避免影响供给者个人工作。

## 本地状态机与恢复

```text
未配对 → 自检 → 待下载/待基准 → 可接单
可接单 → 已领租约 → 输入校验 → 本地排队/执行 → 上传 → 待本模式验收 → 清理 → 可接单
可接单/执行中 → 排空 → 离线
任意阶段 → 凭证撤销/版本不兼容 → 停止新任务 → 清理与人工处理
```

收到相同 attempt/token 时查本地持久记录，返回已有 ack/进度，不再 POST /prompt。客户端崩溃后先恢复 prompt_id 和历史，不立即重跑；平台租约已失效则停止上传正式结果并清理。断网期间不能延长自己的租约，重新连上必须重新验证当前 token；未经平台允许不继续以“以后补账”接新任务。

上传采用分片/可重试单对象权限。明文平台验收，加密仅上传密文并等待买家签名接受；租赁按可用时长结算，不把每个子任务单独售卖。客户端分别显示待验收/待计量/待结算，只有确认应付进入对应收益，不显示上传成功即到账。

## 图像、视频、音频与3D能力包

生图 P0：固定 1 张图、规定尺寸和格式、输入长度/参数上限；模型未确定前不设虚构显存和时长保证。对透明图/色彩空间按 SKU 统一。

视频 P1：除提示词外可能有首帧/参考图，必须校验输入许可和规格；记录模型、seed、帧数、尺寸、帧率、时长、音频约定。若工作流先输出帧，客户端以固定 FFmpeg 配置合成，限制帧文件总量、磁盘占用和编码时间，平台验证最终 MP4。首个拟定规格为 80 帧、16fps、5 秒、512×512、无声，实际基准不通过则不得上架。

主观画质、身份一致性、文字正确等不是仅靠解码可证明的指标；购买前样例与售后标准应匹配真实模型能力，不声称绝对无伪影或精确遵从所有提示。

## 更新、许可、退出与清理

更新包含签名、哈希、依赖清单、变更说明和可回滚版本；运行中先排空再升级，紧急撤销工作流则按订单失败政策处置。旧版本仍在已售合同需要时保留，若存在安全/许可问题不可继续则退款，不悄悄换模型。

ComfyUI 分发的许可证与源码获取责任见 [官方 GPLv3](https://github.com/Comfy-Org/ComfyUI/blob/master/LICENSE)；安装包旁提供适用声明和对应源码/构建材料获取方式。是否构成单一衍生作品需按实际打包方式确定，不能只因拆进程就默认免除义务。模型权重不随 GPL 自动取得分发权。

成功交付/会话结束后1小时内清平台输入/中间态，失败终态后24小时、离线重连后24小时补清。租赁撤权并停止后清工作区/密钥，未清理确认前GPU隔离禁复用。退出撤证/结束租约，个人模型/聊天不误删；回执不证明恶意所有者彻底删除。

## 专项验收补充

三模式端点职责：明文按原受控执行/平台验收；基础加密在适配器内解密、结果离端前加密，私密参数不进平台/普通日志；增强档连同预处理/编码/缓存/插件全部纳入真实证明。租赁同一会话多任务但资源锁不释放，双端就绪起表、到期本地停止、清理完成才能接下一单。

Windows/Linux两引擎的原生生命周期与实例边界见[桌面专项](供给端/01-Windows与Linux供给端需求.md)，Android前台服务/电量/温控/本地槽/安全出站及LMA版本边界见[Android专项](供给端/02-Android与LMA供给端需求.md)。本页ComfyUI的/prompt、/history等只用于该适配器，不强制其他引擎伪装这些路由。

安装取消/磁盘不足、模型损坏、未知节点、错误签名、同任务重送、休眠重启、WebSocket 中断、队列错位、取消竞态、输出上传失败、过期租约、升级回滚、退出清理均需实际验证。测试不得调用 Docker/WSL；不同物理节点的重派演练不能用同机两个进程冒充两台独立 GPU。

## 音频、3D与有限节点安装补充

音频能力包纳入语音/音频生成与获准转写方向，分别冻结模型/声音授权、时长、采样率、声道、编码与产物验收；TTS映射已验证OpenAI Audio Speech子集，ASR另验Transcriptions。3D能力包冻结模型、节点、网格/纹理规格、坐标/单位、GLB等格式与解析资源上限，不执行资产脚本或任意外部纹理引用。音乐/3D采用明确声明且经过SDK验证的Responses结构化资产结果档位，未通过不售，不伪造官方3D端点。它们是完整需求范围，尚未指定已通过的具体模型或节点。

新增节点的安装仅来自平台有限目录，提供方逐包确认；固定代码修订/hash、允许class_type、安装脚本/权限和全部传递依赖。启动导入前核启用目录，未知代码/依赖、Manager安装旁路和运行期隐式pip拒绝。节点变化创建新环境，不原地升级活动venv。平台批准不替代代码风险评估，普通进程/venv不构成插件安全沙箱。

RuntimeSupervisor与EngineAdapter解耦，内核清单摘要贯穿能力、报价/合同、签名执行授权、本地命令和任务状态。新环境先校验、停新单/排空、独占维护、基准后切换；回滚不得恢复已撤销环境或覆盖token/账证。提供方可见版本、节点/模型、更新差异和运行状态。详见[内核封装规范](技术开发/附录-供给端内核封装与替换规范.md)。

## 双端加密下的提供方职责

SellerGateway与内置转发核心在专用低权限服务中运行，UI只见安装/版本/模型/节点、资源/阶段/收益及停止，不提供正文/钥/历史/文件代理。明文输入只在核合同/端点/ISSUED/环境/双围栏后进入受控worker，输出独立钥给买方；任务文件首次写盘前加密，公开权重只读原生加载，不新增全片RAM盘/第二份模型。

重启保留backend ID/最高围栏/密文引用/水位，先query后恢复；钥丢失不盲重算，完整密文可补传。只有实际停算/清理完成才释放显卡，之后交付不占卡；已撤销/替代的计算指令无权再执行。消息、钥轮换/撤销、END/回执、媒体分段与E2E-01—20按[技术08](技术开发/08-端到端加密协议与密钥实现设计.md)，现阶段未实现/未测。
