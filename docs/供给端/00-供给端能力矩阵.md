P11｜v3.0｜2026-10-29｜Windows采用LM Studio CLI体系及完整ComfyUI可替换内核；Linux保留双引擎；Android基于LMA源码二开。操作系统支持与三种交易模式分别建模；均为需求，尚未完成接入。

低开销完整方案（最新用户确认）：用户允许新增隐私档可嵌入LLM内核，LM Studio继续保留兼容。采用llama.cpp C API原生worker、ComfyUI私有管道入口、LMA内部JNI；买卖端加密/平台盲转，任务数据加密而模型保留原生加载，不使用VM/RAM盘/常驻第二份模型。输入准备和密文交付不额外占GPU锁，控制与大数据通道分离。内存/性能为待实测验收预算，完整链路、二进制协议、媒体、恢复及PE-01—PE-08见[完整实施方案](../技术开发/附录-低开销隐私执行完整方案.md)。当前尚未实现或通过设备/密码/性能验证。

完整深化与实施细则见[白皮书阅读导航](../白皮书/00-阅读导航与需求基线.md)和[80项逐项实施规格](../白皮书/15-需求逐项实施规格.md)。本文件保留快捷需求入口；v3.0新增详规、契约和追踪，不代表软件已实现。

C2C约束：设备由用户自愿挂牌，卖家自主定价/时段；订单绑定实际卖家，平台收明确佣金。同单只可在同卖家已披露设备内按约重派，跨卖家结束原单并经买家确认新单。资金与责任见[交易规则](../交易/C2C交易与市场规则.md)。

Windows和Linux都要支持ComfyUI与LM Studio两种引擎，不要求四种组合同时安装。供给者按需安装/连接一种或多种；同一GPU共享平台资源锁，不因两个引擎端口都在线就出现两份可售容量。

Android必须在手机本地执行，不能只是PC遥控面板，也不能把请求转给云端后记成手机算力。其CPU/Vulkan/GPU/NPU后端按实际引擎探测；本版没有“任意手机GPU均可运行ComfyUI”的保证。

## 标准能力描述

每个节点上报并审核以下独立维度：

- `provider_os/arch/os_version`：WINDOWS、LINUX、ANDROID及架构/系统版本。
- `runtime_kind/runtime_version/protocol_version/kernel_environment_digest`：COMFYUI、LMSTUDIO、LLAMA_CPP_NATIVE、ANDROID_LMA_ADAPTER或AUTHORIZED_RELAY，不把某个产品名字当操作系统。
- `resource_kind`：LOCAL_GPU、ANDROID_DEVICE、AUTHORIZED_API；设备、本地执行与外部额度分别计量。
- `accelerator_backend/observed_offload`：CPU/CUDA/其他经测后端和实际卸载情况；无证据不宣称GPU/NPU加速。
- `model_identity`：仓库/修订、权重/分词器哈希、量化、上下文、采样模板、许可；不同量化/上下文不混成同一个SKU。
- `task_types/feature_flags`：文本、图、视频、音频、3D；非流/流、工具、结构化输出、embedding等逐项验证。
- `availability`：设备在线、环境可用、模型已安装/就绪、执行槽/锁、温控/电量/网络、支持模式、区域与证明。
- `benchmark/evidence`：冷启动、首token、tokens/s、端到端时间、内存/显存、持续负载、失败、真机/物理机证据。

状态依次区分“已登记、已安装、已加载、已测试、已准入、在线可售”。下载成功、HTTP 200、`/models`列表、CPU型号、Android前台服务通知均不能单独证明正在提供可售计算。

## 统一适配协议

所有适配器实现describe/probe/prepare/execute/progress/cancel/collect/cleanup/health语义；这是平台内部协议，不宣称第三方原生提供同名接口。控制面生成唯一work_item/attempt/token及合同，适配器保存真实后端request/prompt/job ID，避免超时后盲重试。

流式统一保留顺序、结束原因、token来源和预算；模型能力不支持的字段付款前拒绝。工具调用默认只返回结构化调用建议，不运行供给者本机工具/MCP、shell、浏览器、文件读取。不同引擎API相似不表示默认提示词/上下文/计量或取消相同。

模式规则不变：基础加密端点在节点适配器解密并加密返回；明文平台可处理；增强档必须真实证明整条运行路径。Android普通KeyStore、Linux权限或Windows凭据保护只降低凭据泄漏，不提供设备所有者不可见保证。

后续源代码在本项目`dev/src/client/windows/`、`linux/`、`android/`及`adapters/comfyui/`、`lmstudio/`、`lma/`；协议放`dev/src/client/protocol/`，平台端仍用原目录。模型/安装包/构建依赖/临时缓存分别在本项目runtime内。这里只规划路径，当前没有对应实现。

Linux使用真实Linux原生节点；不在当前Windows机上启动WSL/Docker/虚拟机。Android使用获授权真机，不启动模拟器；本次只核对资料，不安装/构建LMA或接管用户设备。不修改所引用的LMA仓库，也不自动替换用户已安装LM Studio或其他ComfyUI。
