# Android与LMA：移动算力供给需求

P11｜v3.0｜2026-10-29｜关联P11-F57、F59、F61—F68。Android是实际本地执行的供给端；LMA确定为源码二开基座，当前尚未建立派生实现、安装或真机验证。

低开销完整方案（最新用户确认）：用户允许新增隐私档可嵌入LLM内核，LM Studio继续保留兼容。采用llama.cpp C API原生worker、ComfyUI私有管道入口、LMA内部JNI；买卖端加密/平台盲转，任务数据加密而模型保留原生加载，不使用VM/RAM盘/常驻第二份模型。输入准备和密文交付不额外占GPU锁，控制与大数据通道分离。内存/性能为待实测验收预算，完整链路、二进制协议、媒体、恢复及PE-01—PE-08见[完整实施方案](../技术开发/附录-低开销隐私执行完整方案.md)。当前尚未实现或通过设备/密码/性能验证。

本地隐私目标修订（2026-10-29）：本次只要求提高日常读取/普通工具/简单改包成本。LMA派生端的平台任务走内部引擎/JNI或受限IPC，不经过个人聊天/WebView记录，不开放给原本地/LAN API；内容文件应用内加密，Keystore保护静态钥，通知/logcat/备份/诊断不留正文。提供方保留资源/收益/停止界面，普通手机不改标硬件增强。边界与待执行LP验收见[本地防护规范](../技术开发/附录-本地内容隐私防护与分级验收.md)。

完整深化与实施细则见[白皮书阅读导航](../白皮书/00-阅读导航与需求基线.md)和[80项逐项实施规格](../白皮书/15-需求逐项实施规格.md)。本文件保留快捷需求入口；v3.0新增详规、契约和追踪，不代表软件已实现。

C2C约束：设备由用户自愿挂牌，卖家自主定价/时段；订单绑定实际卖家，平台收明确佣金。同单只可在同卖家已披露设备内按约重派，跨卖家结束原单并经买家确认新单。资金与责任见[交易规则](../交易/C2C交易与市场规则.md)。

现行v3.0数据面统一OpenAI/Anthropic入口：明文平台Sub2API类网关；加密买方本机/可信LAN程序与卖方解密/内置转发内核配对，平台仅盲转。全部端遵循相同协议/安全合同，Android为轻量适配和真机本地执行，不装整套中心数据库栈。后端不支持的特性付款前拒绝，详见[网关协议](../协议/统一API与本地加密网关需求.md)。

当前供给内核路线：Windows/Linux隐私LLM以llama.cpp原生worker封装，LM Studio的lms CLI＋llmster＋runtime保留兼容；图像/视频/音频/3D以完整ComfyUI原生内核及有限节点白名单封装；Android基于LMA源码二开。Linux原生双引擎保留。详见[内核封装与替换规范](../技术开发/附录-供给端内核封装与替换规范.md)，当前均设计待实现，第三方许可/实机证据未取得。

## 参考边界

已核对[LMA](https://github.com/wikigsroom/LMA)的README、API/架构/验证文档、构建清单、Manifest及ApiHost，固定参考提交为`5d9e81d59273f2a656763ea3ee3401b2846a18cc`。公开v0.2.0与主分支0.3.0-dev.21分开看：前者文本API，后者有多模态开发代码；登记/下载或开发代码存在不等于手机上运行通过。详细证据见[核查记录](../资料/LMA与LMStudio接入核查-2026-10-29.md)。

平台Android端在本项目内基于固定LMA源码建立独立二开工程，复用和调整原生服务、本地引擎、模型管理、任务/产物及本地API，并新增供给身份、合同、平台调度、加密信封、预算/计量、卖家成交额/扣费/应结收益及清理。LMA原有本地API不等同已经接上本平台。本版不把Android强行安装为桌面ComfyUI/LM Studio，而是用统一适配协议封装原生引擎。

## 产品页面与首次使用

页面为设备/模型、能力自检、共享设置、活动任务、收益、数据/退出。首次先说明设备使用和流量/电量影响 → 主动选择模型/所需组件和下载体积/许可 → 安装校验 → 平台配对 → 真机基准 → 选择共享时段/网络/电量条件 → 用户主动开始共享。

APK不包含大模型或因安装/升级暗中下载全部目录；用户选择下载时才能安装已展示的依赖，HF等下载令牌与平台/推理密钥分开。不能把手机相册、通讯录、短信、个人聊天、麦克风或全盘访问当共享前提；输入只能是分配任务的数据或用户明确通过系统文件选择器导入的文件。

采用当前参考ARM64/Android9+作为初始兼容候选，最低系统/ABI和加速后端以锁定版本、真机测试冻结，不承诺任意Android都兼容。硬件/内存/存储不足则解释并不上架对应模型。

## 执行能力与模型

文本作为最先验证的能力，支持有界messages、输出上限、非流/流、结束原因、取消和模型版本；图像/视频/音频按本地引擎、模型组件、配方、内存和真机基准逐项扩展。保留多模态方向，但不将LMA规划目录全部写成平台已能售卖。

每个可售模型记录权重/量化/tokenizer/模板/引擎/配方版本、许可、上下文/输入限制、实际CPU/GPU/Vulkan等后端、冷启动/首token/吞吐、峰值内存、稳定性。NPU/GPU仅在真正使用并验证后展示；没有该后端就写CPU，不从SoC宣传推导吞吐。

手机端文本聊天、公开本地API、其他本地多模态任务和平台订单共用一个执行门闩，初期一个重任务槽。用户自用开始时先停止接新共享单，再排空/按约定中止已接单；不能两套队列各自认为自己独占。模型切换/卸载先检活动任务，不能加载失败仍自报可售。

## 后台、电量、热和网络

共享由用户主动启动，持续可见通知显示接单状态、当前任务和立即停止。前台服务类型、启动条件、通知权限、后台与重启行为按实际Android/targetSDK及分发渠道验证；不因为叫前台服务就承诺24小时常驻，也不把所有类型一概套用6小时时限。参考项目使用specialUse，仍需本平台实际用途适配。

默认只在充电、非计费Wi-Fi及用户允许时段接新任务；移动数据、非充电共享由用户主动开启并配置每日流量/时长上限。低电量、系统热压力、内存/磁盘不足暂停新单，严重情况尽力取消并报告已交付/失败。具体电量阈值是可配置初值，上线前按机型负载实测，温控读不到时显示未知并采用保守规则，不伪造温度/功率。

锁屏、Doze、省电模式、厂商后台杀进程、系统撤权、来电及网络切换均是必测故障；任务/attempt持久化，恢复先核token，不盲重跑已可能完成的推理。重启不自动恢复售卖，用户选过的自启也须满足系统限制和设备条件；不得要求root或绕过系统/用户限制。

手机只主动出站连接平台HTTPS/WSS，受限长轮询可作为网络回退；NAT、Wi-Fi到蜂窝切换、断线均不要求公网IP或端口映射。LMA参考本地/LAN HTTP并非公网安全方案；平台不把它直接暴露互联网、不从云端连接用户内网任意地址。本地引擎默认loopback且鉴权，平台凭证只给本端适配器。

## 三模式、计费和隐私

Android提供明文服务与加密基础档：前者平台可处理内容，后者由买家加密给手机适配器、手机本地解密推理并加密结果；设备所有者仍可能看到内容。LMA本身未提供平台所需端对端协议，必须单独实现并验收。Android Keystore/应用沙箱不证明手机所有者看不到推理明文，不给普通手机增强档标签。

首批用有输入/输出上限的固定服务请求价；token计费须统一模型/tokenizer、usage来源与重复/中断规则，未核验估计不直接扣款。用户本地模型服务挂牌不受“上游订阅转供授权”同一个开关控制，但模型/引擎商用和再分发许可仍必需。

本版不把Android执行槽宣传成独立显卡租赁。未来若售“移动执行槽时租”，另定义设备资源、可用性、后台限制和计量合同，不复用整卡独占标签或把设备个人控制权交给买家。

买家数据与手机个人聊天分库/命名空间，禁自动合并历史/训练。平台/推理/下载密钥用途分离，使用系统可用的受保护存储且不进WebView/普通日志；应用升级保留身份和计量幂等状态，卸载/清数据后平台撤销旧身份，历史应付仍按账户查询。LMA“私有SharedPreferences”的参考实现不能被写成已做硬件加密。

## 清理、停止和真机验收

停止共享先关新单、排空/按合同取消、撤销活动访问和补偿流程；任务缓存按三模式留存，个人模型由用户选择保留，不能误清自用聊天/文件。离线重连先补清，旧token结果无正式交付/收益资格；恢复不能复制前一次卖家结算款。

至少两款实际获授权Android真机，覆盖一款最低支持系统/较低资源和一款较新系统/高资源（未有设备不得假报通过）。逐个机型/引擎/模型验证安装、加载、真推理、基础加密、受限文本/多模态、连续负载、锁屏/后台、温控电量、断网切网、用户自用抢占、停止/恢复/清理和计费。桌面断言、模拟HTTP及APK构建通过只代表相应检查，不能代替真机。

## LMA二开与内核版本边界

本路线要求源码级集成，不以独立代理App转调另一台PC或仅参考界面替代。保留LMA的Java服务/EngineHost/ApiHost与native桥，新增平台协议、租约/环境校验、轻量转发、加解密和共享/收益；Kotlin可与Java互操作，Compose不是原LMA已有技术事实。原聊天/API与共享任务必须使用同一推理门闩，个人记录和平台任务隔离。

Android可执行内核通过受签APK中的固定native组件替换，不增加从应用可写目录下载并执行任意so/dex的热加载机制；模型和数据配方仍用户自主下载。升级需排空/停止并保存任务/代次/清理状态，升级后先恢复查询和补清、重新验证能力，再开放新单。上游公开版、开发版和本平台派生版分别登记，实际CPU/GPU路径如实披露。详见[内核规范](../技术开发/附录-供给端内核封装与替换规范.md)。

## 手机加密执行的完整协议要求

LMA二开端在内部Java/JNI落实[技术08](../技术开发/08-端到端加密协议与密钥实现设计.md)的独立钥用途、端点信任/撤销、PREPARED/ISSUED、流头/AAD、END/FINAL、原密文补传/回执与分段缓存；不增Go/Node/Python中心栈或云代算。共享正文不进个人聊天/WebView/ApiHost/logcat/相册/备份，UI保留共享状态/收益/停止。

进程重启先query后端与最高围栏，临时钥丢失按有效合同重授权或失败，不重算/重扣。原结果完整密封给买方后无需正文钥即可补传；原手机身份/钥丢失不由平台恢复旧内容。E2E-01—20适用项、LP与真实手机资源预算均待验证，不自动获得增强标签。
