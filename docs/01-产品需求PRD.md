# 算力共享平台：产品需求 PRD

P11｜v3.0｜2026-10-29｜用户自发共享闲置显卡/手机的C2C市场。完整范围为三模式、加密基础/增强两档及Windows/Linux/Android供给端。当前仅需求设计，无实现、真实设备验收或实单。

低开销完整方案（最新用户确认）：用户允许新增隐私档可嵌入LLM内核，LM Studio继续保留兼容。采用llama.cpp C API原生worker、ComfyUI私有管道入口、LMA内部JNI；买卖端加密/平台盲转，任务数据加密而模型保留原生加载，不使用VM/RAM盘/常驻第二份模型。输入准备和密文交付不额外占GPU锁，控制与大数据通道分离。内存/性能为待实测验收预算，完整链路、二进制协议、媒体、恢复及PE-01—PE-08见[完整实施方案](技术开发/附录-低开销隐私执行完整方案.md)。当前尚未实现或通过设备/密码/性能验证。

本地隐私目标修订（2026-10-29）：用户将当前目标收敛为拦住初级/中级用户的日常查看与普通工具读取、增加本地拦截成本，不以高级内存分析为验收目标。首期推荐原生低权限隔离、任务级密文工作区及文件/日志/引擎API出口封闭；TEE/保密GPU不是此前提，普通VM只作可选评估。这是独立的本地防护策略，不新增服务模式、不把普通端改标ATTESTED_CONFIDENTIAL；原有硬件增强保留为独立远期能力。既有“基础档所有者可见”表示技术上仍可能访问，不表示默认向提供方展示内容。具体动作与LP-01—LP-14见[本地防护规范](技术开发/附录-本地内容隐私防护与分级验收.md)，全部待实现/未执行。

本轮修订：小程序React＋Taro优先，独立Web React＋Vite；部署/HTTPS/运维与可观测性延后。以[当前范围](技术开发/附录-本轮范围与端侧选型修订.md)、[协议转发](技术开发/07-统一协议网关与Sub2API改造.md)和[赛事收单](技术开发/13-支付退款账务与渠道结算.md)覆盖相冲突段落；原F/T编号保留，不代表全部在本轮实施或已通过。

完整深化与实施细则见[白皮书阅读导航](白皮书/00-阅读导航与需求基线.md)和[80项逐项实施规格](白皮书/15-需求逐项实施规格.md)。本文件保留快捷需求入口；v3.0新增详规、契约和追踪，不代表软件已实现。

当前供给内核路线：Windows/Linux隐私LLM以llama.cpp原生worker封装，LM Studio的lms CLI＋llmster＋runtime保留兼容；图像/视频/音频/3D以完整ComfyUI原生内核及有限节点白名单封装；Android基于LMA源码二开。Linux原生双引擎保留。详见[内核封装与替换规范](技术开发/附录-供给端内核封装与替换规范.md)，当前均设计待实现，第三方许可/实机证据未取得。

## 已确认的商业定位与范围

用户A自愿把自己拥有或合法使用的闲置设备挂牌，设置价格、时段和能力，向用户B出售模型服务或受控GPU使用时段；平台承担市场撮合、软件、计量、规则、信誉、交易协助与争议处理。设备不来自平台自营，也不以平台采购用户服务后再销售为商业结构。平台主要收入为明确佣金/服务费，不把GMV作为平台收入，不承诺保底购买闲置时间。

Windows LLM基于LM Studio的lms CLI、llmster及可替换推理runtime封装；图像/视频/音频/3D基于完整ComfyUI可替换内核及有限节点白名单封装。Linux保留原生双引擎；Android基于LMA源码二开，作为真正的本地执行端。获上游许可的订阅/API仍可作为用户挂牌的条件分支；未经许可不能因C2C或代理包装而转供。增强档只由具备真实证明的用户设备提供，平台不以专用自营供给替代。

此前v2.0的平台采购再销售假设已纠正。现行商业规则见[C2C交易与市场规则](交易/C2C交易与市场规则.md)；旧评审只作历史，不作为价格、收入或责任依据。具体模型、硬件、正式费率、支付资格和首发工期尚待验证。

## 统一协议与转发产品形态

全部已售模型/媒体数据请求从OpenAI或Anthropic兼容入口进入，平台同时提供两类协议；基础文本包含Chat Completions、Responses、Messages的已发布JSON/SSE子集。按模型发布能力，未知参数或无法保真转换时明确拒绝；控制面与引擎内部协议另行适配。

明文使用平台Sub2API类网关。加密要求买方在本机/可信LAN运行标准API加密网关，平台仅中转密文；卖方程序解密后通过内置Sub2API类内核转发给本地引擎/获授权上游，并加密回传。两个端点均需明确，不能让平台明文网关代替卖方解密。增强档还需把解密/转发内核及整个执行路径纳入真实保护。

兼容SDK通过Base URL/凭据和必要版本配置接入，模式/实际卖家/预算由已确认路由合同绑定，不强制私有必填JSON字段，不静默改明文或代购。手机采用同合同的轻量内核，保持真实本机推理。详细规范及源代码候选边界见[统一API与本地加密网关](协议/统一API与本地加密网关需求.md)。

## 双边价值与角色

- 卖家A：自主报名、核验设备与许可、挂牌能力/时段/价格、选择接单规则，自愿暂停新单并排空；从真实成交中取得扣费后的结算款。知悉电费、损耗、自用影响和故障责任，没有订单时不保证收益。
- 买家B：选择卖家/设备，或在预算、规格、时限和隐私条件下请求匹配；付款前确认实际卖家、价格和可见方，按对应模式取得结果或可用时段，能够评价及申诉。
- 平台：提供身份与资格核验、目录/基准、匹配、软件、支付适配、计量、履约证据、佣金、信誉与争议工具。承担自身系统和规则义务，不默认成为每笔算力服务的卖家。
- 运营/客服/财务：分权处理挂牌、许可、争议、卖家结算与平台费用；后台权限不能解开加密内容。

同一账户可兼任买家和卖家。自助个人挂牌、卖家定价、基本信誉/评价与申诉属于基础范围；受控试点可以限量，不以只邀企业供应商、采购合同或平台自有机器替代C2C验证。

## 三模式权益和边界

| 模式 | 买家向卖家购买什么 | 内容可见边界 | 计费证据 |
| --- | --- | --- | --- |
| 端对端加密·基础档 | 指定卖家执行端处理、输入输出对平台隐藏 | 买家及执行卖家可见；合法Relay和上游可见 | 买家接受的任务，或可信API用量 |
| 端对端加密·增强档 | 经证明的保护区执行，基础设施所有者也无明文权限 | 买家和受证明代码可见；平台及设备管理员不可见 | 对应硬件/代码证明及任务接受 |
| 受控整卡租赁 | 特定卖家GPU的独占受控工作区 | 初始标准档平台/卖家可能可见 | 就绪后已确认可用占用时间 |
| 明文 | 卖家提供、平台可预检/核验的标准推理服务 | 平台及必要执行卖家可处理内容 | 合格完整任务或可信用量 |

交易模式和隐私档位分别冻结。卖家、挂牌、设备集合、地区、规格、费率、费用承担、验收和退款均写入订单，不静默换卖家、改价或降隐私。明文平台解码是规则内的技术验收，不表示平台买入结果再销售。

## 核心流程与换卖家规则

卖家自助报名→身份/设备使用权/许可与收款核验→原生客户端及真实基准→自主挂牌价格/时段→买家选定或匹配并确认卖家→获准渠道付款→卖家设备执行→对应验收/有效租时→卖家应结款及平台佣金→渠道结算到账→评价与售后。

服务任务最多一次在同一卖家已披露的合格设备集合内重派，保持规格、区域、预算和总期限；加密更换端点需买家重新放钥。跨卖家应结束原单，买家确认新卖家/报价后创建关联新单，不能后台透明替换。某卖家只有一台设备时，不假设必有备用节点。

GPU图像初拟1张1024×1024 PNG，视频试验5秒/512×512/16fps/80帧/无声MP4；模型、许可、硬件及真实基准分别准入。本地文本先有界固定请求，token价在计量可信后开放。租赁为审核应用/参数/模型和自己的队列文件，无宿主管理员、桌面、任意节点或脚本权限；Android本版按任务挂牌，不冒充整卡租赁。

## 价格、资金和责任

卖家决定挂牌价；平台建议价和自动定价均需卖家明确采用。初拟只向卖家收成交佣金，正式费率与渠道费用承担待确认；无隐性买家附加费。GMV、卖家成交款/应结净额、平台费用、退款和补偿分开，不能套用采购价与销售价双价模型。

平台须核实允许该业务及个人卖家的持牌渠道、实际卖家识别/收款、退款和结算能力；Machine Pay按量收款不自动证明C2C资金路径可用。不以平台普通账户归集再私下转账模拟获准分账；不自建可转让/可提现钱包。

卖家故障、买家原因、平台过错、原因不明分别取证和按公示合同处理。平台过错或明确限额保障才产生对应平台补偿，不默认保底采购/无限垫付。必要身份核验、平台治理、税费/信息报送、数据处理和内容义务不能以C2C概括免除。

## 安全与环境

基础加密不防执行设备所有者；增强档必须覆盖CPU预处理、GPU使用、编码、临时盘、日志和结果回传，绑定新鲜证明与买家认可放钥策略。普通进程、Keystore、DPAPI、HTTPS及整卡独占不满足增强标签；防平台主动换钥/网页代码还需可独立核验的买家端及身份链。

全部本地工作在本项目原生环境；禁止Docker、WSL、虚拟机或Android模拟器，不接管其他项目引擎。Windows/Linux用物理机，Android用真机，未有证据只能标未执行。浏览器调用后关闭不用标签。

## 端对端加密的完整执行需求

两端为买方本机/可信LAN网关与指定卖方受限执行服务，平台无内容私钥/万能恢复钥。输入/输出、对象、方向、attempt/epoch分钥，身份/回执/更新另分用途；首次信任与轮换须独立确认。供给端默认不展示prompt/结果/预览/原始日志，只展示组件/模型/节点、资源/收益和停止。当前本地防护提高普通读取门槛，不承诺高级内存攻击或硬件增强。

先PREPARED绑定加密上下文、不锁GPU；资金/输入/许可/环境/容量通过才ISSUED。执行端核签名/租约/双围栏再解密，内置转发核心经管道/内部JNI执行；媒体首次持久化前加密，实际停算/清理后释放资源，密文补传与签收不额外占卡。终块/标准终态/买方签名验收缺一不自动成交；断线不盲重跑/重扣、不静默换模式/卖家。

具体钥生命周期、消息/签名/AAD、二进制限额、分段缓存/Range及20项未执行子场景以[技术08](技术开发/08-端到端加密协议与密钥实现设计.md)为准。BINARY_STREAM_1与旧JSON分档，协商/Schema/独立评审/跨端实测未过不发布，文档完成不表示可售。
