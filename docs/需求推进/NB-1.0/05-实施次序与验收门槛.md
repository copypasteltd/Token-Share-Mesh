## 3. 验收证据怎么记录

每个NB-R子项沿原F/T记录至少两个场景：正常路径与失败/越权/并发/恢复之一。证据包含版本、端、设备/系统/内核/profile、输入夹具编号、预期、实际、请求/订单/会话/账单引用及结论；不上传真实prompt/私钥作为证据。

静态文档检查只能说明编号/引用/算例一致。类型/组件测试说明局部代码行为，模拟接口说明模拟条件下流程。物理设备、支付宝真机、真实渠道、密码独立验证和性能数据分别记录，不能互相替代。截图/GIF必须标清AI约束图、演示UI或真实产品采集；本轮不制作假产品录屏。
