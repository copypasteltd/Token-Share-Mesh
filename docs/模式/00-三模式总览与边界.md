# 算力共享平台：三模式总览与边界

P11｜v3.0｜2026-10-29｜需求设计，尚未实现。用户已要求分为端对端加密、显卡租赁、明文三种模式，并确认加密模式同时规划“平台不可见”和“平台及显卡所有者不可见”两档。本次确认不等于硬件、支付权限或具体售价已经就绪。

低开销完整方案（最新用户确认）：用户允许新增隐私档可嵌入LLM内核，LM Studio继续保留兼容。采用llama.cpp C API原生worker、ComfyUI私有管道入口、LMA内部JNI；买卖端加密/平台盲转，任务数据加密而模型保留原生加载，不使用VM/RAM盘/常驻第二份模型。输入准备和密文交付不额外占GPU锁，控制与大数据通道分离。内存/性能为待实测验收预算，完整链路、二进制协议、媒体、恢复及PE-01—PE-08见[完整实施方案](../技术开发/附录-低开销隐私执行完整方案.md)。当前尚未实现或通过设备/密码/性能验证。

本地隐私目标修订（2026-10-29）：用户将当前目标收敛为拦住初级/中级用户的日常查看与普通工具读取、增加本地拦截成本，不以高级内存分析为验收目标。首期推荐原生低权限隔离、任务级密文工作区及文件/日志/引擎API出口封闭；TEE/保密GPU不是此前提，普通VM只作可选评估。这是独立的本地防护策略，不新增服务模式、不把普通端改标ATTESTED_CONFIDENTIAL；原有硬件增强保留为独立远期能力。既有“基础档所有者可见”表示技术上仍可能访问，不表示默认向提供方展示内容。具体动作与LP-01—LP-14见[本地防护规范](../技术开发/附录-本地内容隐私防护与分级验收.md)，全部待实现/未执行。

完整深化与实施细则见[白皮书阅读导航](../白皮书/00-阅读导航与需求基线.md)和[80项逐项实施规格](../白皮书/15-需求逐项实施规格.md)。本文件保留快捷需求入口；v3.0新增详规、契约和追踪，不代表软件已实现。

C2C约束：设备由用户自愿挂牌，卖家自主定价/时段；订单绑定实际卖家，平台收明确佣金。同单只可在同卖家已披露设备内按约重派，跨卖家结束原单并经买家确认新单。资金与责任见[交易规则](../交易/C2C交易与市场规则.md)。

全部模型/媒体调用经OpenAI或Anthropic兼容入口；明文采用平台Sub2API类网关，加密采用买方本机/可信LAN加密、平台密文中转、卖方解密/内置同类转发内核。租赁工作区内调用复用同一入口且不额外按次收费；控制面仍独立。详见[协议与网关](../协议/统一API与本地加密网关需求.md)。

当前供给内核路线：Windows/Linux隐私LLM以llama.cpp原生worker封装，LM Studio的lms CLI＋llmster＋runtime保留兼容；图像/视频/音频/3D以完整ComfyUI原生内核及有限节点白名单封装；Android基于LMA源码二开。Linux原生双引擎保留。详见[内核封装与替换规范](../技术开发/附录-供给端内核封装与替换规范.md)，当前均设计待实现，第三方许可/实机证据未取得。

## 产品入口与交易对象

| 产品入口 | 买家买到什么 | 默认计费依据 | 内容处理与验收 | 供给范围 |
| --- | --- | --- | --- | --- |
| 端对端加密模式·基础档 | 买家与指定执行端之间加密的生成/调用 | GPU完整任务、本地文本有界请求、核验API用量 | 平台只处理中转密文和元数据，买家本地验收，执行节点可见 | 已准入GPU、Android本地端、有下游许可的Relay |
| 端对端加密模式·增强档 | 在基础档之上，数据使用过程也处于可验证的保密执行边界 | 单独报价的任务，不假定与基础档同价 | 买家验证硬件、运行环境、密钥接收端和出口策略；平台及供给者管理员均无明文权限 | 通过端到端验证的专用供给；普通 Windows 消费级节点不得自动上架 |
| 显卡租赁模式 | 一段时间内指定显卡的独占受控工作区，可反复提交受支持任务 | 已确认的可用占用时长 | 验收就绪、独占、可用性和时长；图片数量及主观质量不是租赁计费依据 | 自有/有权出租且通过测试的实体 GPU，不将订阅额度包装为显卡 |
| 明文模式 | 平台可处理内容的标准生成/模型调用 | 固定GPU任务、本地文本有界请求/可信用量、授权API用量 | 平台预检、内容验收与售后 | 已准入GPU/LM Studio/Android、有下游许可API |

“明文”指对受授权的处理方可见，网络仍使用 HTTPS，存储仍加密。租赁描述的是资源交付方式，加密描述的是隐私边界，二者在技术上可以组合；产品仍保持上述三个入口，租赁单另列隐私属性，不因租赁自动得到增强档保护。

## 两种供给与三种模式分别记录

供给来源分本地设备与授权上游，资源为`LOCAL_GPU`、`ANDROID_DEVICE`、`AUTHORIZED_API`，模式为`E2E`、`GPU_RENTAL`、`PLAINTEXT`。Windows采用LM Studio CLI体系与完整ComfyUI可替换环境，Linux保留原生双引擎，Android基于LMA源码二开本地执行，见[多端矩阵](../供给端/00-供给端能力矩阵.md)。模式不取代引擎/设备类型。

| service_mode | privacy_profile | resource_kind | 初始范围/启用条件 |
| --- | --- | --- | --- |
| E2E | PLATFORM_BLIND | LOCAL_GPU | 基础档，可信准入；买家使用经验证的加密端，完成密文回执与故障测试 |
| E2E | PLATFORM_BLIND | ANDROID_DEVICE | 手机适配器本地解密/推理/加密，所有者可见，真机/协议通过才可售 |
| E2E | PLATFORM_BLIND | AUTHORIZED_API | 获授权的本地 Relay；A 和上游可见，平台不可见；不得走平台解密代理 |
| E2E | ATTESTED_CONFIDENTIAL | LOCAL_GPU | 增强档，专用硬件/软件证据、买家验证及原生部署可行性全部通过才可售 |
| GPU_RENTAL | STANDARD | LOCAL_GPU | 原生、受控、整卡独占时租；披露平台及供给者可能访问内容 |
| GPU_RENTAL | PLATFORM_BLIND | LOCAL_GPU | 后续组合能力，复用基础档协议并完成会话测试后单独启用 |
| PLAINTEXT | STANDARD | LOCAL_GPU / ANDROID_DEVICE / AUTHORIZED_API | 标准平台处理，本地LLM与上游API分开，上游仍需转供授权 |

其余组合默认拒绝。增强手机/上游API、增强租赁、Android整卡租赁、任意代码裸机均不自动可售。本地文本初始按有界固定请求，token价须有可信计量；不同引擎不共用虚假精确余额。

## 一笔订单只采用一份合同

合同快照至少包括：模式、隐私档位、资源类型、SKU/环境/工作流版本、处理方和区域、可见信息、执行端身份策略、计费单位、价格/预算、准备与履约期限、验收责任、取消退款、证据与留存、卖家成交/费用/结算及责任规则、政策版本。任何模式或隐私降级都要求新报价与买家明确选择；已付单不能后台改成明文或降低硬件保护。

端对端基础档的工作站所有者可以看到执行内存和文件；平台是否看不到内容，还依赖买家端没有把明文/密钥送回平台。若要抵御平台主动换公钥或篡改网页，须使用可独立核验的本地客户端/SDK及独立确认的端点密钥；仅由平台网页提供全部加密代码和公钥，不能覆盖这种攻击。

增强档需要保护整个数据路径：CPU 解密和预处理、CPU/GPU 传输、GPU 内存与计算、编码、临时盘、结果加密、调试与崩溃转储。只有 GPU 有一个证明而 Windows 管理员仍能读 CPU 明文，不满足增强档。未经验证的显卡型号、进程隔离、文件加密均不足以获得此标签。

## 用户流程差异

共同入口：选择模式 → 比较可售能力 → 阅读价格、数据可见方和失败规则 → 生成不可变报价 → 按实际支付合同履约 → 获取对应账单。

- 加密：确认接收端身份/增强档证明 → 本地校验并加密输入 → 准入和付款 → 指定端处理并加密返回 → 本地验收签名回执 → 收费、退款和供给应付分别落账。
- 租赁：选设备、环境和时长预算 → 短期占位并准备 → 实测就绪/买家确认 → 开始按时间计费 → 工作区内反复调用 → 续租或结束 → 停止访问、清理后再出租。
- 明文：平台预检 → 报价付款 → 受控执行 → 平台验收 → 交付与售后。

## 范围与验收责任

v2.2 C2C及双协议完整范围包含三个入口与两个加密档位。建议基础迭代先实现明文 GPU、加密基础档、受控整卡租赁；增强档先验证可行性、后开放真实专用供给。视频规格和订阅授权分别验证，不按四周旧计划承诺本次全部范围。

价格、指定模型、兼容硬件、Machine Pay 对各交易时序的实际支持、供给者出款渠道仍需证据；不存在可售证明时界面显示“规划/未开放”，不伪造库存、收益或隐私能力。

## 本次内核路线对本模式的约束

本模式下的执行环境由提供方主动选择并经平台批准，Windows LLM用CLI体系、媒体用完整ComfyUI/有限节点，Android用LMA源码二开。环境摘要进入合同/当前执行授权，既售任务或有效租赁期间不可安装节点/替换内核；更新先停新单/排空。基础加密仍对设备所有者可见，增强需覆盖全部实际组件的真实证明；Android整卡/默认增强限制不变。
