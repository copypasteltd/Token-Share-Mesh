# 明文模式：完整需求

P11｜v3.0｜2026-10-29｜关联 P11-F07—F30、F31—F32、F49—F56。继承标准服务市场能力，明确为平台可处理内容的模式。

完整深化与实施细则见[白皮书阅读导航](../白皮书/00-阅读导航与需求基线.md)和[80项逐项实施规格](../白皮书/15-需求逐项实施规格.md)。本文件保留快捷需求入口；v3.0新增详规、契约和追踪，不代表软件已实现。

C2C约束：设备由用户自愿挂牌，卖家自主定价/时段；订单绑定实际卖家，平台收明确佣金。同单只可在同卖家已披露设备内按约重派，跨卖家结束原单并经买家确认新单。资金与责任见[交易规则](../交易/C2C交易与市场规则.md)。

明文核心改为平台Sub2API类网关：双协议入口、合同/预算/资源准入、受控转发和标准响应，可评估基于Sub2API裁剪改造。账户池/余额收费/跨卖家failover不直接继承；实际卖家与唯一C2C账仍为权威。加密订单绝不进入此管线解密，见[协议与网关](../协议/统一API与本地加密网关需求.md)。

本次供给内核修订：Windows LLM以lms CLI＋llmster＋可替换推理runtime封装；图像/视频/音频/3D以完整ComfyUI原生内核及有限节点白名单封装；Android基于LMA源码二开。Linux原生双引擎保留。详见[内核封装与替换规范](../技术开发/附录-供给端内核封装与替换规范.md)，当前均设计待实现，第三方许可/实机证据未取得。

## 定义、用户和交付

买家通过网页/Agent 提交提示词、图片或获准的模型请求，平台可读取并按已披露目的处理，再调度 GPU 或调用获授权上游。适合希望直接获得标准生成结果、接受平台预检和售后的用户；不要求买家管理内容加密密钥或远程工作区。

明文是应用层可见范围，不是裸传输。登录、输入、调度、结果下载均经 HTTPS/安全设备通道；平台对象存储和凭证加密，密钥分权，访问有审计。供给者不将内容用于训练、转卖或私人使用，平台不因可见而默认公开、训练或全员可查。

| 内容 | 平台处理服务 | 已准入执行节点 | 上游 API | 客服/财务 |
| --- | --- | --- | --- | --- |
| 提示词和原始素材 | 按预检/执行所需可读 | 只领取自己任务所需数据 | 仅获授权 API 所需部分 | 客服按授权查看指定证据；财务无正文 |
| 结果 | 可解码验收、存储和交付 | 本任务范围 | 依具体上游处理合同 | 默认只看状态，排障看内容需授权/约定权限 |
| 密钥与支付凭据 | 专门服务最小权限 | 仅本设备/连接器凭据 | 自己的 API 认证范围 | 不出现在一般日志/工单 |

## 服务目录与任务合同

Windows LLM以lms/llmster/runtime封装供文本等实测能力，完整ComfyUI环境供图像/视频/音频/3D批准配方；Linux保留双引擎，Android基于LMA源码二开提供手机本地执行。各端按环境/模型/配方实测，目录/下载不代表可售。本地LLM先按上下文/输出有界请求价，token口径和流式另验；不与外部订阅共用授权库存开关。见[多端矩阵](../供给端/00-供给端能力矩阵.md)。

GPU 图像初拟为一张 1024×1024 PNG、明确模型/工作流版本，固定任务价。视频为独立 SKU，试验规格 5 秒/512×512/16fps/80帧/无声 MP4；须真实基准和许可通过才上架。模型名称、硬件门槛、时限和价格尚待选择实测，不虚构速度。

获授权 API 可按请求或输入未缓存/缓存/输出 token 等实际协议用量计价；需冻结模型、上下文/输出上限、工具能力、usage 映射、取整方式、最大费用和流式失败规则。MiniMax Coding Plan 等个人订阅不因进入明文模式就获得转供权；[订阅专项](../07-订阅供给接入与授权.md)的授权开关继续适用。

买家只能选择审核参数，不能上传任意工作流节点/执行脚本/路径/外部 URL。需要长期自由试参数并愿按占用时间付费时，应进入显卡租赁，不能把租时单记为固定结果单。

## 完整流程

1. 目录显示真实可售能力、参考样例、区域和第三方处理范围；无合格供给则不可售。
2. 平台检查类型、大小、图像解码、参数范围、输入政策和授权；敏感/不适合第三方处理的内容说明后拒绝或由买家改选可售加密服务，不暗中改变模式。
3. 冻结价格和合同：报价初拟 15 分钟、准入预留 90 秒；付款前重查容量。报价不是占 GPU；不得承诺无依据的即时开始。
4. 按真实 Machine Pay 合同获取可履约凭证；创建任务并分配匹配节点，使用 10 秒心跳、45 秒租约和 fencing_token。
5. 专用 Runner 校验输入，执行锁定工作流，经受限上传发送产物；平台独立解码、验证数量/格式/尺寸、版本关联、必要内容检查和坏包规则。
6. 唯一验收成功与最终付款证据分别入账，满足合同后发正式结果权益；结果保留 7 天、下载链接 5 分钟、重查/重领免费。
7. 按C2C订单和费用版生成唯一卖家应结款/平台佣金，经争议窗和获准出款渠道结算；买家可申请售后。

生图从可履约凭证通过且输入就绪时起初拟 300 秒总处置时限，含排队、一次重派、上传与平台验收，不包含用户付款前等待和银行退款到账；实际最迟期限必须随 SKU 冻结。视频另配时限。节点变更不能换模型/区域/授权范围；一单最多两个尝试，买家不为重派多付费。

## 收费与退款

标准 GPU 服务按完整成功任务/件计费，GPU 秒、温度、电费只做标明可信度的成本诊断。相同任务重传、慢节点、失败尝试不增加买家账。无法交付完整规格则全退实付/释放授权；未执行取消全退，运行中取消按中止与验收竞态及购买前政策处理，P0 不按“半张图片”收费。

参数合法但主观不满意可申请按样例和售后政策复核；图片美观、身份一致性、文字正确不由文件解码自动保证。平台营销性退款与供给者违约冲正分开，不任意扣除合格供给收益。

API 用量可能不同于固定 GPU 任务：流已交付、usage 丢失、取消和上游完成未知按真实合同处理，不套用“没有最终完整文件就一律零成本”。费用有确认上限；没有可信 usage 不以估算直接扣款；支付不支持预算/后结算时不开放该分支。

## 内容处理与运营权限

后台默认显示模式、SKU、设备、状态、错误码、时序、成交、平台费用和卖家结算摘要，不展开正文。买家提供的排障授权须限定订单、人员、目的和时间，访问留痕；访问正文和财务出款分权。日志、埋点和异常栈不记录 prompt、图片、密钥或完整上游响应。

审核可能生成内容摘录或检查证据，应与源文件同等保护；不能称源文件删掉就表示所有含内容衍生物都已删除。对公开演示/样例、数据训练分别取得明确授权，私人订单不自动进入公共图库。

支持按模式/SKU/地区/节点暂停新售，既有查询、已购结果和售后保留。监控质量、容量和差异账，不能用“明文更易检查”宣称所有节点完全诚实或质量完全可证明。

## 数据保存与验收

平台输入及含输入的临时审核对象在终态后 24 小时内清理；在线结果默认 7 天；节点成功交付后 1 小时内清理，失败终态后 24 小时、离线重连后 24 小时内补清。默认应用日志 30 天、无正文，滚动备份 7 天并保留删除标记防复活。交易/许可/结算证据按正式政策保存，不能夹带输入正文。

关键验收为：平台能够完成已声明的内容预检与产物解码；未授权角色不能查看正文；供给仅见本任务；固定价/幂等/重派/取消/退款/实际出款成立；清理覆盖衍生证据与备份；选择加密或租赁后不会错误走本模式处理管线。

## 本次内核路线对本模式的约束

本模式下的执行环境由提供方主动选择并经平台批准，Windows LLM用CLI体系、媒体用完整ComfyUI/有限节点，Android用LMA源码二开。环境摘要进入合同/当前执行授权，既售任务或有效租赁期间不可安装节点/替换内核；更新先停新单/排空。基础加密仍对设备所有者可见，增强需覆盖全部实际组件的真实证明；Android整卡/默认增强限制不变。
