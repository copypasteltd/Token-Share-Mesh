# v2.2 双协议与本地加密网关变更

历史快照：本文件保留v2.2当时的变更/核验状态，现行需求详见[v3.0白皮书](../白皮书/00-阅读导航与需求基线.md)；历史JSON登记不覆盖。

P11｜v2.2｜2026-10-29｜承接 v2.1 C2C 商业基线，新增用户明确提出的标准协议、Sub2API 类内核与本地/局域网加解密程序。当前仅需求文档；没有产品实现、设备/支付/密码或 SDK 验收。

## 新增确认

1. 全部已售 AI 模型/媒体的数据请求和响应经 OpenAI 或 Anthropic 兼容入口。平台支持两类入口，各能力按真实后端发布，不能静默丢弃不支持字段。
2. 明文采用 Sub2API 类中心网关，可评估直接基于候选源码改造。
3. 加密路径需要买方本地/可信 LAN 程序及卖方执行端程序：标准请求 → 加密 → 平台密文中转 → 卖方解密 → 内置同类转发内核 → 后端；响应反向加密回传。
4. 基础档仍信任卖方普通执行环境；增强档还须保护解密/转发内核和整个推理路径，不能被本地程序或 HTTPS 替代。

## 追踪与优先级

保留 P11-F01—F68 / T01—T68，新增 F69—F80 / T69—T80，共80项功能与80项同号主验收。新增12项为 P0 架构/基础合同要求；具体增强、视频及授权上游仍分别受 P1 / P1-AUTH 门槛约束，不因新增网关就提前可售。

F28 的高级 SDK/MCP 扩展保持 P2，但标准 SDK 可连接的基础双协议入口属于新增 P0。F54 允许由已经明确确认的路由配置解析模式/合同，普通标准请求不强制添加私有 JSON 字段；缺配置/授权仍拒绝。F56 更新现行版本与完整追踪范围。

主文档、三模式、多端、交易规则和当前评估补充本次约束。v2.1 C2C 规则继续成立，其变更记录/登记表/核验是历史快照；v2.0 错误采购假设继续只作历史。当时入口为 v2.2，现行入口已升至v3.0。
