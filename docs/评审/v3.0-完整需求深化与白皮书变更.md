## 新细化的关键规则

- E2E先建立无执行权的INPUT_PENDING/PREPARED上下文，绑定job/attempt/token/recipient，再加密上传/提交封装；资金/输入/许可/资源全部准入才ISSUED，换端重新核验封装。
- 独立保存支付、履约、接受、退款和卖家结算状态；稳定幂等键查原单，UNKNOWN不自动重购/重出款；无稳定键不按相同正文猜重复意图。
- 租赁预留、准备、双端ready、起表、有效可用区间、到期本地停工、撤权、清理后解锁分别建模；不靠锁TTL证明清理。
- 价格/佣金/费用承担/卖家/模式合同冻结；佣金按最终保留成交额整单取整，租赁按合并可用毫秒一次取整；补偿与成交另账。
- 数据按类别/角色/用途/期限治理；增强须覆盖内核/CPU/GPU/编码/日志等全部明文路径，基础档不伪称卖家不可见。
- ADR01—14、CFG01—31、EVID E01—E15、RISK R01—R22与W01—W16将方案、参数、风险和外部依赖变成可追踪工作。
