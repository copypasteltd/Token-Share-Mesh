# 供给端内核封装路线核查

P11｜2026-10-29｜只读核查官方文档及固定源码。用户决定Windows LLM基于LM Studio CLI、媒体基于完整ComfyUI及有限节点白名单、Android基于LMA二开；决定不等于已实现或已获商业许可。

| 来源 | 核实的有限事实及设计影响 |
| --- | --- |
| [LM Studio headless](https://lmstudio.ai/docs/developer/core/headless) | 官方提供无GUI的llmster及桌面headless路径，列有Windows原生获取方式；本项目选择llmster主路线，不运行网页中的安装脚本 |
| [lms CLI](https://lmstudio.ai/docs/cli) | CLI支持模型/服务管理并标注MIT；CLI的许可不自动覆盖daemon、推理runtime和权重 |
| [daemon up](https://lmstudio.ai/docs/cli/daemon/daemon-up) | 可启动daemon，并有机器可读输出；已存在实例会返回现状，因此还须校验进程/配置归属 |
| [server start](https://lmstudio.ai/docs/cli/serve/server-start) | 支持绑定/端口设置；使用受限本地API完成推理，不解析终端聊天输出冒充JSON/SSE |
| [runtime管理](https://lmstudio.ai/docs/cli/runtime/runtime) | runtime可列举、获取和选择，证明CLI/daemon/runtime应分别管理；任意精确版本自动安装/隔离不能据此假定已验证 |
| [daemon update](https://lmstudio.ai/docs/cli/daemon/daemon-update) | 面向最新版本，要求先停止daemon；不能直接用作有付费任务时的无感热替换或固定版本回滚承诺 |
| [LM Studio桌面条款](https://lmstudio.ai/app-terms) | 2026-08-23版本的许可用途与对第三方服务/分发有限制；须核实际内核发行物，不能从CLI MIT推断整个LM体系可收费转供 |
| [ComfyUI自定义节点](https://docs.comfy.org/basic-concepts/custom-nodes) | 安装节点同时涉及代码、依赖和版本/冲突，项目白名单需覆盖依赖闭包及启用目录；Registry可发现不是平台批准 |
| [ComfyUI服务路由](https://docs.comfy.org/development/comfyui-server/comms_routes) | prompt/history/queue/interrupt等按固定内核版本核验；取消范围不能仅由平台job_id猜测 |
| [LMA固定架构源码](https://raw.githubusercontent.com/wikigsroom/LMA/5d9e81d59273f2a656763ea3ee3401b2846a18cc/docs/ARCHITECTURE.md) | 基座含Java服务、WebView、EngineHost/本地native进程；公开文本实现使用CPU并由APK携带native库，不从可写目录执行下载代码。新桥可用Kotlin互操作，不虚构已有Compose架构 |
| [LMA仓库](https://github.com/wikigsroom/LMA)及[固定许可证](https://github.com/wikigsroom/LMA/blob/5d9e81d59273f2a656763ea3ee3401b2846a18cc/LICENSE) | 采用固定源码二开，不只参考思路；保留MIT声明并独立核依赖/权重，公开版/开发线/本平台派生版分开。主分支浏览不升级本项目固定基线 |
| [OpenAI语音生成](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)、[转写](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create) | Speech/Transcriptions为音频协议候选；逐字段、二进制/JSON及取消需冻结SDK验收，不将音乐或3D任务伪装成TTS |
| [Responses参考](https://developers.openai.com/api/reference/resources/responses)、[后台任务](https://developers.openai.com/api/docs/guides/background)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs) | 采用标准文本/结构化结果描述音乐或3D资产是本平台设计，非官方原生3D功能宣称；实际create/retrieve/cancel及SDK尚未验证 |

本次没有下载二进制/模型、执行官方脚本、构建LMA、启动ComfyUI/LM Studio或调用设备/真实支付。没有打开本地浏览器标签页。独立配置/精确版本替换/回滚、节点代码安全、各媒体模型、安卓后台和商业许可全部待对应PoC/真机证据。
