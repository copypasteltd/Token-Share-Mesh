## 选型建议与不直接继承的能力

需求已确认明文采用 Sub2API 类网关，本地加解密程序内带同类转发内核。实现优先评估复用协议层与连接器；实际 fork/模块抽取、进程隔离及许可证处理在冻结源码后决定，当前未做产品代码。

中心服务与端侧内核分开裁剪：平台原生网关、桌面原生模块/受限子进程、Android 轻量协议与本机执行适配。不能因为有 Go 服务就假定手机能跑完整中心栈，不能调用 Docker/WSL/虚拟机来绕过构建或验收。

C2C 订单/实际卖家、资源锁、支付/结算和明文/加密权限为本项目权威。共享账户池轮转、跨卖家 failover、充值余额、自营售卖视图、内容日志或未经授权的订阅连接器均不能直接启用。全部流量都必须经过合同、许可、预算和执行权限校验。

完整需求见 [统一 API 与本地加密网关](../协议/统一API与本地加密网关需求.md)。
