# 五套跨端概念设计：分组与一致性约束

本轮只制作设计稿，源码开发与仓库发布保持暂停。以下把用户的“分割一致性”落实为分组隔离、单图单页、组内组件和跨端视觉一致性。图中设备、卖家、价格、状态均为演示信息，不表示真实可售资源或已上线能力。

| 约束编号 | 固定规则 |
| --- | --- |
| DS-001 | 共5个互相独立的风格组；每组恰好3张主稿：小程序首页、小程序服务详情、Web算力工作台，共15张 |
| DS-002 | 小程序主稿1024×1536竖图，Web主稿1536×1024横图；每张只画一个完整页面，不拼屏、不叠手机、不透视、不加样机外壳 |
| DS-003 | 5组使用相同业务主体、页面职责、主要字段、示例价格和交互状态，避免内容不同干扰风格比较 |
| DS-004 | 每组单独冻结背景/面板/正文/主色/边框/提示色、文字层级、圆角、阴影、图标线宽、按钮、标签和卡片规则 |
| DS-005 | 组内首张首页是视觉参考。详情和Web通过同一Sub2API模型、参考图编辑生成；只能引用本组，不交叉混用其他组图 |
| DS-006 | 品牌为Token Share Mesh，中文应用名“算力共享”；共同标记为三个相连节点组成的简洁网格符号，组内保持同一画法 |

| DS-008 | Web复用本组主色、图标、卡片、状态标签和按钮，通过左侧导航、主区域、右侧服务摘要适配横屏；不将手机截图塞进Web |
| DS-009 | 首页提供“明文 / 端对端加密 / 显卡租赁”，选中“端对端加密”；分类“全部 / 对话 / 图像 / 视频”中选中“全部” |

| DS-013 | 网关状态固定为“本地网关未连接”；主要操作为“连接网关并继续”或“连接网关”，不表示点击后直接扣款/执行 |

| DS-016 | 模型固定gpt-image-2.5，high质量，PNG；实际调用指定sub2-image-gen脚本，不切换其他服务商或模型 |
| DS-017 | 检查实际输出文件、尺寸、单图单页、业务语义和组内一致性。机器校验只证明文件/尺寸，视觉一致性通过实际看图核验 |

## 页面职责

1. 首页：发现和比较个人卖家的资源，呈现三模式、分类、资源卡和底部导航。
2. 详情：核对同一卖家、能力、隐私边界和价格，再连接本地网关继续。
3. Web工作台：在同一设计系统下浏览资源、查看合同摘要/预算和网关状态，连接自己的应用。

生成图是概念视觉稿，不是已经可交互的代码页面，也不替代实际支付、设备或加密验收。
