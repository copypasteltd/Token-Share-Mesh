## 00.1 开发范围

开发根目录 `E:\dev\sandbox\支付宝黑客松\算力共享平台\dev`。所有命令以项目根目录运行，代码/测试/工作流/新工具落在 dev；规范在 docs，运行数据在 runtime。本文件记录设计基线，源码实现与原生验证进展另在 dev/progress 登记，不用设计状态覆盖真实实现记录。Go 测试遵从单模块结构随 dev/src 包存放，跨端入口及证据仍在 dev/tests。

C2C 平台撮合真实个人卖家；端对端加密、受控 GPU 租赁、明文三模式保留。小程序是主交易入口，标准模型 SDK 经已确认路由调用；所有者知道组件、资源与收益，但默认不展示买方正文。
