# 原生数据库与核心服务验证

入口：在项目根目录运行 `python -X utf8 dev/tools/原生数据库验证.py`。

该工具只启动本项目下载的 PostgreSQL 17 临时原生实例，执行后关闭；不连接其他数据库、不启动虚拟化或模型。凭据随机生成，测试输出不包含连接串，实例文件保留在项目 runtime 便于复核。

Go 采用单模块 `dev/src/go.mod`，其测试源码依 Go 工具规则与包相邻，跨模块集成场景位于 `dev/src/tests/integration/`；本目录保留跨端验证入口、说明和 `../evidence/` 证据。这些服务/数据库场景不等于支付宝登录、支付、GPU、Android 或完整产品主验收通过。
