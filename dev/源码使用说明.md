# 源码使用说明

当前轮次R004：已实现原生Go身份/控制HTTP子集、数据库基础、市场资格、报价与建单。真实授权渠道、支付、供给端和前端仍待完成，见[实施进度](progress/README.md)。

## 1. 原生工具

所有命令在项目根目录执行：

```powershell
python -X utf8 dev/tools/获取原生工具链.py
python -X utf8 dev/tools/原生开发.py version
python -X utf8 dev/tools/原生开发.py mod download
```

固定版本和归档摘要位于 [toolchain.lock.json](toolchain.lock.json)；Go 依赖位于 [go.mod](src/go.mod)、[go.sum](src/go.sum)。工具下载/解包和全部缓存只在项目 runtime，不修改系统 PATH，不安装系统数据库服务。Go 默认从地区代理传输依赖，保留签名校验数据库和 go.sum；可通过 `P11_GOPROXY` 切换来源。

## 2. 原生数据库与集成测试

```powershell
python -X utf8 dev/tools/原生数据库验证.py --round R004
python -X utf8 dev/tools/核验原生源码.py --round R004
python -X utf8 dev/tools/整理原生验证证据.py --round R004
```

自动在项目 runtime/db/integration 下初始化随机凭据、仅监听 loopback 的临时 PostgreSQL 17，运行真实 Go/数据库测试，再停止该实例。实例数据保留以便复核，不连接其他数据库。最新测试输出和摘要位于 [tests/evidence/](tests/evidence/)。没有测试数据库时直接运行 Go 测试会明确跳过原生数据库场景，不能把该结果当作完整通过。

中文路径通过临时盘符别名交给原生数据库工具，仍使用项目内同一批文件；确认实例停止后才移除本工具创建的别名。若关闭未确认，保留别名并报错以便按该实例恢复，不能删除其他项目的盘符映射。初始化仅对这份可丢弃测试目录跳过最后的全盘同步；测试服务器保留正常 fsync/WAL，不据此声称断电恢复已验收。

第二条命令核验锁定依赖、Go格式和vet，并构建Windows/Linux的admin和API命令；Linux仅交叉编译，未执行Linux程序。第三条命令严格汇集34项实际局部用例和构建证据，源文件摘要变化即拒绝复用旧构建结果。[Go依赖/许可登记](licenses/go-dependencies.json)只覆盖本轮Go模块。

本套不启动 Docker、WSL、虚拟机或 Android 模拟器。Go 相邻 `*_test.go` 和 dev/src/tests/integration 均在同一个 Go 模块内；dev/tests 提供跨端测试入口和证据。

## 3. 迁移与检查命令

有本人明确选择的开发 PostgreSQL 17 连接后，通过环境变量 `P11_DATABASE_URL` 提供连接串，不将凭据写进源码或命令参数：

```powershell
python -X utf8 dev/tools/原生开发.py run ./api/cmd/p11-admin migrate
python -X utf8 dev/tools/原生开发.py run ./api/cmd/p11-admin check-schema
```

迁移器使用同事务互斥与不可变摘要；已执行迁移发生变化就拒绝，未来增加版本只能新增 forward migration，不修改001。迁移元数据在 p11_meta，基础60表及前向003的2张身份表（当前62表）在 p11；不提供自动 down 或清库命令。

## 4. 当前接口与授权边界

R004新增支付宝RSA2适配、单次挑战与当前会话以及13个原生HTTP操作，权威合同仍有93操作；实际[路由登记](src/api/internal/http/routes.json)随源码嵌入并对照契约，未实现路径不给假成功。源码和合成渠道响应测试不表示真实支付宝应用已联调，OAuth不等于KYC或卖家资格，首次注册只授BUYER。

配置步骤和完整环境变量见[双语使用指南](repository/USAGE.md)。显式配置已选开发库、应用ID/主体字段、RSA/HMAC密钥文件及浏览器Origin后运行：

```powershell
python -X utf8 dev/tools/原生开发.py run ./api/cmd/p11-api
```

命令要求迁移版本3，只监听数字loopback，默认127.0.0.1:8787；不自动迁移、不提供测试身份开关、不启动模型或资金。HTTP本机开发须显式P11_INSECURE_LOOPBACK=1并使用精确loopback浏览器源；开发Cookie单独命名，默认Cookie仍Secure/HttpOnly/Strict。不增加部署/HTTPS/可观测性规划。

小程序：内存随机verifier→MINIAPP挑战→my.getAuthCode→POST兑换→仅内存持有首次令牌→Bearer访问。浏览器：WEB挑战绑定Cookie/state→核源回调→POST兑换→只读会话Cookie＋内存CSRF；写操作另核Origin及X-CSRF-Token。前端及回调窗口未实现，不把backend测试当小程序/Web整体可用。会话查询不重发秘密，重启/注销后重新授权；授权UNKNOWN不盲重兑原码。

业务事务在幂等回放前再次核用户/角色和已绑定会话的版本、期限及撤销。API key不能购买或管理会话；密钥原值只首次返回，同意图回放返回409 SECRET_ALREADY_ISSUED及原key引用，不重显secret。角色撤销不因重登恢复，封禁账户不能重登复活。

当前交易只涵盖市场→报价→明确确认建单→读取WAITING_PAYMENT，不占GPU或冻结/收取渠道资金。小时会话/续租、可信usage、预算和完整转发仍待开发。
