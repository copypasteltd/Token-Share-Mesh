# 源码使用说明

当前轮次 R001：已开始实现 Go 原生后端基础、数据库迁移、API 密钥核心和可靠任务组件。完整平台仍在开发，具体已实现表与全部待办以 [实施进度](progress/README.md) 为准；小程序、Web、供给端、支付与完整协议链尚未交付。

## 1. 原生工具

所有命令在项目根目录执行：

```powershell
python -X utf8 dev/tools/获取原生工具链.py
python -X utf8 dev/tools/原生开发.py version
python -X utf8 dev/tools/原生开发.py mod download
```

固定版本和归档摘要位于 [toolchain.lock.json](toolchain.lock.json)；Go 依赖位于 [go.mod](src/go.mod)、[go.sum](src/go.sum)。工具下载/解包和全部缓存只在项目 runtime，不修改系统 PATH，不安装系统数据库服务。Go 默认从地区代理传输依赖，保留签名校验数据库和 go.sum；可通过 `P11_GOPROXY` 切换来源。

## 2. 原生数据库与集成测试

```powershell
python -X utf8 dev/tools/原生数据库验证.py
python -X utf8 dev/tools/核验原生源码.py
python -X utf8 dev/tools/整理原生验证证据.py
```

自动在项目 runtime/db/integration 下初始化随机凭据、仅监听 loopback 的临时 PostgreSQL 17，运行真实 Go/数据库测试，再停止该实例。实例数据保留以便复核，不连接其他数据库。最新测试输出和摘要位于 [tests/evidence/](tests/evidence/)。没有测试数据库时直接运行 Go 测试会明确跳过原生数据库场景，不能把该结果当作完整通过。

中文路径通过临时盘符别名交给原生数据库工具，仍使用项目内同一批文件；确认实例停止后才移除本工具创建的别名。若关闭未确认，保留别名并报错以便按该实例恢复，不能删除其他项目的盘符映射。初始化仅对这份可丢弃测试目录跳过最后的全盘同步；测试服务器保留正常 fsync/WAL，不据此声称断电恢复已验收。

第二条命令核验锁定依赖、Go格式和vet，并构建Windows CLI及Linux CLI；Linux仅交叉编译，未执行Linux程序。第三条命令汇集10项实际用例和构建证据，源文件摘要变化即拒绝复用旧构建结果。[Go依赖/许可登记](licenses/go-dependencies.json)只覆盖本轮Go模块。

本套不启动 Docker、WSL、虚拟机或 Android 模拟器。Go 相邻 `*_test.go` 和 dev/src/tests/integration 均在同一个 Go 模块内；dev/tests 提供跨端测试入口和证据。

## 3. 迁移与检查命令

有本人明确选择的开发 PostgreSQL 17 连接后，通过环境变量 `P11_DATABASE_URL` 提供连接串，不将凭据写进源码或命令参数：

```powershell
python -X utf8 dev/tools/原生开发.py run ./api/cmd/p11-admin migrate
python -X utf8 dev/tools/原生开发.py run ./api/cmd/p11-admin check-schema
```

迁移器使用同事务互斥与不可变摘要；已执行迁移发生变化就拒绝，未来增加版本只能新增 forward migration，不修改001。迁移元数据在 p11_meta，60张领域表在 p11；不提供自动 down 或清库命令。

## 4. 当前接口与授权边界

本轮密钥组件已提供服务层创建、鉴权、只读列表、撤销和路由归属验证，API key 只能取得标准允许的有限调用权限，不能管理账户密钥或授予后台角色。账户会话/OAuth、HTTP适配和CSRF仍在后续待办，本轮不提供冒充真实支付宝登录的公共入口。

密钥原文只在第一次创建结果中返回，不进入数据库/幂等记录。重复相同创建意图复用原key的公开引用，但不重显secret；HTTP层将按已澄清的控制契约返回409 SECRET_ALREADY_ISSUED。后台任务仅允许查询/清理/通知类，UNKNOWN资金创建不能作为通用任务重试。
